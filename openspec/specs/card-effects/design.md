# card-effects — 設計

效果的執行機制(節點、續體、待命時效、登記方式)見 `effect-tree/design.md`。本檔記錄卡片規則的實現方式與效果文的解讀。

## 規則機制

### 「このターン中の次のバトル」

待命以 `expires: "next_battle"` 排程,戰鬥開始時由 `engine._arm_next_battle_standbys` 綁定到這場戰鬥(改為 `"battle"`),條件不符而沒生效的在戰鬥結束時移除。

E-013 / S-057 仍以「擁有者攻擊時消耗」實作:兩張只能在自己的回合使用,而一回合中的戰鬥都由回合玩家攻擊(`game-engine` › 需求「戰鬥開始確認(バトル・イン)」 › 情境「只有回合玩家能宣告攻擊」),所以「自己攻擊的下一場」就是「下一場」。

### 「〇〇の術」的費用與加成

- `spell_cost(game, player, page, card, slot=)` 依使用的魔物計算;未指定魔物時取可用魔物中最低的費用,供畫面顯示與宣告前的 MP 檢查。
- 加成待命(`spell_bonus`)只在使用魔物相符時消耗。

### 可選的減費(M-008)

- 宣告術(攻擊或防禦)時,若減費可用且付得起原價,建立 `spell_discount` 決策,之後才續行宣告(`_open_battle_in` / `_finish_defense_declaration`)。決定記在宣告資料的 `discount`,開戰付費時依此計算。
- `spell_cost(..., discount=False)` 不計可選的減費。可選的待命在 `data["optional"]` 標記。
- 術的魔力加減只作用在術本身、不低於 0(`_side_total`)。

### 翻 / 回翻自己的魔本

- 「翻 / 回翻自己魔本」的效果一律經過 `primitives.own_book_turn_effect`,由它記錄本回合用過(`page_effect_used` / `page_back_effect_used`);回翻 0 張時不記錄。
- P-010 / P-018 另外設定限制旗標(`page_effect_limited` / `page_back_effect_limited`),之後同方向的效果不發生,並發出 `page_turn_restricted` 事件。P-010 / P-018 的使用條件為「未用過且未受限制」。
- 回翻最多回到第一頁;`turn_back_pages` 回傳實際張數,沒有回翻時不發事件,P-019 依實際張數計算。
- 受傷翻頁、開始階段翻頁、結束階段強制翻頁不是效果,不經過這裡。

### 「減少對手 MP」的紀錄(E-018)

- 經 `reduce_opponent_mp` / `mark_opp_mp_reduced` 記錄到 `opp_mp_reduced_turns`,只保留本回合與前一回合。
- 會記錄的效果:E-018、S-020、P-002、P-019(被動效果也算「使用」)、E-004(對手 MP 為 1 以上時)。

### ジャマー(M-026)

- 魔物的啟動效果使用前拍快照,效果(含其後的選擇)完成後才詢問持有 M-026 的一方。使用則以 `_restore_effect_state` 還原。
- 還原:玩家、modifier、待命、戰鬥內容。
- 不還原:行動權、pass 次數、戰鬥輪替。對手的費用與「本回合已使用」照算。
- 雙方都有 M-026 時可連鎖。效果使戰鬥開始 / 結束或遊戲結束時不提供。夥伴效果、被動效果、擲幣確認鏈中的 M-012 / M-019 不觸發。

### 術卡使用次數以頁計數

`spell_page_uses` 以頁計數,上限由 `spell_use_limit` 查詢掛鉤決定(M-024 兩隻分身體時 ビライツ 每張每回合 2 次)。

## 行為決定與理由

以下「相關規格」除非另外註明,皆指 `card-effects` › 需求「第二彈 68 種卡全數可用」下的情境。修改相關卡片前先看這裡;要改變 `Confirmed` 或 `Project Decision` 的決定,須先與專案負責人確認。

### E-001 在使用時選擇魔物

**相關規格:** `effect-tree` › 需求「Standby 節點跨回合續體與時效」 › 情境「E-001 於下回合開始階段觸發」;`effect-tree` › 需求「延遲效果重新檢查目標」

**決定:** 使用 E-001 時就選擇魔物,下回合開始階段才 +3000;選定的魔物在那之前離場時無效果,不改選其他魔物。

**理由:** 效果文「次のターンのスタートフェイズまで【スタンバイ】し…自分の魔物1体を選ぶ」可以讀成使用時選,也可以讀成開始階段效果解決時才選;規則書沒有定義待命效果的選擇時點。

**依據:**
- E-001 效果文
- 專案負責人決定

**確認狀態:** `Project Decision`

### 「〇〇の術」以使用術的魔物判定

**相關規格:** 情境「「〇〇の術」以使用術的魔物判定」

**決定:** P-001、P-005、P-007、M-008 的「〇〇の術」以使用術的魔物判定,不看術卡上的對應魔物;不限使用對象的指示術由該魔物使用時也適用。

**理由:** 「スギナの術」可以讀成「スギナ對應的術卡」或「スギナ使用的術」,效果文不足以唯一決定。

**依據:**
- P-001、P-005、P-007、M-008 效果文
- 專案負責人決定

**確認狀態:** `Project Decision`

### 「このターン中の次のバトル」只作用於下一場

**相關規格:** 情境「「このターン中の次のバトル」只作用於下一場戰鬥」

**決定:** P-001、P-007、M-008、S-019、S-026 的效果只作用於本回合的下一場戰鬥;條件不符時隨該戰鬥結束而消失,不留到之後的戰鬥。

**理由:** 字面是「本回合的下一場戰鬥」,不是「下一場符合條件的戰鬥」。

**依據:**
- 各卡效果文

**確認狀態:** `Confirmed`

### 無術攻擊也算「次のバトル」

**相關規格:** 情境「S-026 的不可防禦適用於無術攻擊」

**決定:** 無術攻擊(M-027)的戰鬥也是「下一場戰鬥」:S-019 / S-026 的「相手は防御できない」適用;P-001 限「ガッシュ・ベルの術で攻撃するとき」,不適用,效果隨該戰鬥結束。

**理由:** 無術攻擊走完整的戰鬥流程,是一場戰鬥;S-019 / S-026 的效果不限定用術攻擊。

**依據:**
- S-019、S-026、P-001 效果文
- `game-engine` › 需求「無術攻擊」

**確認狀態:** `Inferred`

### M-008 在宣告術時選擇是否減費

**相關規格:** 情境「M-008 減費由玩家選擇」

**決定:** 在下一場戰鬥宣告スギナ的術(攻擊或防禦)時,由該玩家選擇「少付 1 MP,該術魔力 -1000」或「不使用」。

**理由:** 效果文為「1低いコストで使うことができる。そうしたなら…」,是否減費在使用術的時點決定。

**依據:**
- M-008 效果文

**確認狀態:** `Confirmed`

### M-008 的詢問細節

**相關規格:** 情境「M-008 減費由玩家選擇」

**決定:** 只付得起減費後的費用時直接使用、不詢問;「本来のコスト」已是 0(P-005、最後一頁、指示術)時無法「1低いコスト」,不詢問也不減魔力;逾時預設不使用。

**理由:** 付不起原價時「不使用」不是可行的選擇;本來費用為 0 時無法再低 1,也就沒有「そうしたなら」的魔力 -1000;逾時沿用「可選效果預設不使用」的慣例,且只有付得起原價時才會詢問。

**依據:**
- M-008 效果文
- 房間逾時代打的既有慣例(`online-room`)

**確認狀態:** `Inferred`

### S-026 / S-057 擲出正面時不詢問是否使用

**相關規格:** 情境「S-026 / S-057 擲出正面時不詢問是否使用」

**決定:** 「オモテなら、次の効果を使える」擲出正面時直接設置待命,不詢問是否使用。

**理由:** 宣告使用卡片時就已表示意願,且整張卡只有這一個效果。

**依據:**
- S-026、S-057 效果文
- 專案負責人決定(已寫入 AGENTS.md 的「〜できる」規則)

**確認狀態:** `Project Decision`

### 「自分の魔本をめくる/もどす効果を合計1回」計入 E-005

**相關規格:** 情境「E-005 計入「自分の魔本をめくる/もどす」合計1回」

**決定:** E-005 翻 / 回翻自己的魔本也算這類效果,限制卡本身算 1 次。E-005 先翻過就不能用同方向的 P-010 / P-018;先用了 P-010 / P-018,E-005 同方向的結果不發生(E-005 本身仍可使用);反方向不受影響。

**理由:** E-005 的「自分の魔本を2枚もどす / めくる」就是 P-010 / P-018 所指的效果。

**依據:**
- P-010、P-018、E-005 效果文

**確認狀態:** `Confirmed`

### P-018 在第一頁也能使用

**相關規格:** 情境「P-018 在第一頁也能使用」

**決定:** 魔本在第一頁時也能使用 P-018:棄掉卡片、不回翻、不觸發對手 P-019,但仍算本回合唯一一次回翻效果。

**理由:** 效果文沒有限制,與 P-010 在最後一頁也能使用的處理一致。

**依據:**
- P-018 效果文

**確認狀態:** `Confirmed`

### 回翻 0 張不算用過回翻效果

**相關規格:** 情境「回翻依實際張數」

**決定:** 在第一頁使用 E-005 擲得正正時不回翻,也不算用過「回翻自己魔本」的效果,之後仍可使用 P-018。

**理由:** 沒有發生回翻。P-018 本身則依「限制卡本身算 1 次」另外計算。

**依據:**
- E-005、P-018 效果文

**確認狀態:** `Inferred`

### P-013 依魔物卡張數翻頁

**相關規格:** 情境「P-013 依魔物卡張數翻頁」

**決定:** 對手每有 1 張魔物卡入墓翻 1 張:疊兩張的魔物整隻入墓算 2 張、裝甲體單獨入墓算 1 張、P-006 棄掉的頂層與從魔本棄掉的魔物卡也算;夥伴卡、術卡不算。

**理由:** 效果文是「相手の魔物カード1枚が捨て札になるたびに」,以卡片張數計。

**依據:**
- P-013 效果文

**確認狀態:** `Confirmed`

### E-027 由各方玩家自己選擇

**相關規格:** 情境「E-027 由各方玩家選擇」

**決定:** 對手選擇保留哪張夥伴、從魔本哪一頁取;自己亦同。只有一個選項時不詢問。

**理由:** 效果文明寫「相手は…選び」「自分は…選び」。

**依據:**
- E-027 效果文

**確認狀態:** `Confirmed`

### E-027 取出的夥伴裝在哪一隻

**相關規格:** 情境「E-027 由各方玩家選擇」

**決定:** 可裝備的魔物有多隻時,由取出夥伴的一方選擇裝在哪一隻。

**理由:** 效果文只寫「場に出す」,沒有指定;放到場上是該玩家的動作。

**依據:**
- E-027 效果文

**確認狀態:** `Inferred`

### E-018 被限制成減 0 時仍算使用過

**相關規格:** 情境「E-018 減 0 時仍算使用過減少 MP 的效果」

**決定:** E-018 因直前回合的限制而減 0 時,仍算本回合使用過「減少對手 MP」的效果;連續回合使用時,第二次起都減 0。

**理由:** E-018 本身就是減少對手 MP 的效果,使用了就算,與實際減少多少無關(E-004 的註記同樣以「使用」判定)。

**依據:**
- E-018、E-004 效果文

**確認狀態:** `Inferred`

### M-025 由玩家選擇放回的空頁

**相關規格:** 情境「M-025 放回羅布諾斯可選擇不使用」

**決定:** 放回羅布諾斯時,由玩家選擇放回哪一個空頁。

**理由:** 效果文只寫「自分の魔本の空いているページにもどす」,沒有指定哪一頁;放回是玩家的動作。

**依據:**
- M-025 效果文

**確認狀態:** `Inferred`

### M-026 完整還原

**相關規格:** 情境「M-026 ジャマー於對手使用魔物效果後立即詢問」

**決定:** 使用 M-026 時,遊戲內容還原到對手的魔物效果解決前。

**理由:** 「無効にする」可以只取消尚未發生的部分,也可以還原已發生的變化;專案負責人選擇完整還原。

**依據:**
- M-026 效果文與 `jammer` 圖示的規則
- 專案負責人決定

**確認狀態:** `Project Decision`

### M-026 還原的範圍

**相關規格:** 情境「M-026 ジャマー於對手使用魔物效果後立即詢問」

**決定:** 還原玩家、modifier、待命與戰鬥內容;對手的費用與「本回合已使用」照算;行動權與戰鬥輪替維持目前的值。效果使戰鬥開始 / 結束或遊戲結束時不提供;夥伴效果、被動效果不觸發。

**理由:** 被無效的是效果,不是使用效果的行動本身,所以費用與使用次數照算;流程狀態還原會讓行動順序錯亂。

**依據:**
- M-026 效果文
- 規則書的ジャマー使用時機

**確認狀態:** `Inferred`
