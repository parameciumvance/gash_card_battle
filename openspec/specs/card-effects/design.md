# card-effects — 設計

效果的執行機制(節點、續體、待命時效、登記方式)見 `effect-tree/design.md`。本檔記錄卡片規則的實現方式與效果文的解讀。

## 規則機制

### 「このターン中の次のバトル」

待命以 `expires: "next_battle"` 排程,戰鬥開始時由 `engine._arm_next_battle_standbys` 綁定到這場戰鬥(改為 `"battle"`),條件不符而沒生效的在戰鬥結束時移除。

E-013 / S-057 仍以「擁有者攻擊時消耗」實作:兩張只能在自己的回合使用,而一回合中的戰鬥都由回合玩家攻擊(`game-engine` › 需求「戰鬥開始確認(バトル・イン)」 › 情境「只有回合玩家能宣告攻擊」),所以「自己攻擊的下一場」就是「下一場」。

### 「〇〇の術」的費用與加成

- `spell_cost(game, player, page, card, slot=)` 依使用的魔物計算;未指定魔物時取可用魔物中最低的費用,供畫面顯示與宣告前的 MP 檢查。
- 加成待命(`spell_bonus`)只在使用魔物相符時消耗。

### 可選的減費(M-008)

- 宣告戰術(攻擊或防禦)時,若減費可用且付得起原價,建立 `spell_discount` 決策,之後才續行宣告(`_open_battle_in` / `_finish_defense_declaration`)。決定記在宣告資料的 `discount`,開戰付費時依此計算。
- `spell_cost(..., discount=False)` 不計可選的減費。可選的待命在 `data["optional"]` 標記。
- 戰術的魔力加減只作用在戰術本身、不低於 0(`_side_total`)。

### 翻 / 回翻自己的魔書

- 「翻 / 回翻自己魔書」的效果一律經過 `primitives.own_book_turn_effect`,由它記錄本回合用過(`page_effect_used` / `page_back_effect_used`);回翻 0 張時不記錄。
- P-010 / P-018 另外設定限制旗標(`page_effect_limited` / `page_back_effect_limited`),之後同方向的效果不發生,並發出 `page_turn_restricted` 事件。P-010 / P-018 的使用條件為「未用過且未受限制」。
- 回翻最多回到第一頁;`turn_back_pages` 回傳實際張數,沒有回翻時不發事件,P-019 依實際張數計算。
- 受傷翻頁、開始階段翻頁、結束階段強制翻頁不是效果,不經過這裡。

### 「減少對手 MP」的紀錄(E-018)

- 經 `reduce_opponent_mp` / `mark_opp_mp_reduced` 記錄到 `opp_mp_reduced_turns`,只保留本回合與前一回合。
- 會記錄的效果:E-018、S-020、P-002、P-019(被動效果也算「使用」)、E-004(對手 MP 為 1 以上時)。

### ジャマー(M-026)

- 魔物的啟動效果使用前拍快照,效果(含其後的選擇)完成後才詢問持有 M-026 的一方。使用則以 `_restore_effect_state` 還原。
- 還原:玩家、modifier、待命、戰鬥內容。
- 不還原:行動權、pass 次數、戰鬥輪替。對手的費用與「本回合已使用」照算。
- 雙方都有 M-026 時可連鎖。效果使戰鬥開始 / 結束或遊戲結束時不提供。搭檔效果、被動效果、擲幣確認鏈中的 M-012 / M-019 不觸發。

### 戰術卡使用次數以頁計數

`spell_page_uses` 以頁計數,上限由 `spell_use_limit` 查詢掛鉤決定(M-024 兩隻分身體時 ビライツ 每張每回合 2 次)。

### 啟動效果「限自己回合」(M-018)

- `Activated.own_turn` 由 `engine._use_field_ability` 在時機檢查旁檢查:非回合玩家使用時拒絕 `ability.timing`,在支付 MP 與標記已使用之前。時機(`timing`:戰鬥中與否)與回合歸屬是兩個獨立條件。
- `api/views._ability_view` 輸出 `own_turn`,前端據此在對手回合停用按鈕。
- 檢視對手翻開的頁一律用 `PeekOpponentOpenPages`(E-014、M-018),發出只對使用者揭露卡片的 `pages_peeked`。

### E-010 借用搭檔效果

- E-010 的選項以 `OpponentPartneredMamodo(usable_only=True)` 列出:只列有 `reg.ACTIVATED` 的搭檔,排除只有被動觸發的 P-013、P-019。
- `BorrowPartner` 加 `borrow_partner` modifier(`data={"card", "used"}`,本回合有效),只記卡號,不綁魔物。
- 使用走獨立指令 `use_borrowed_effect`(`engine._use_borrowed_effect`,非戰鬥中與戰鬥效果步驟都可送):依該卡 `reg.ACTIVATED` 的時機、搭檔效果失效限制、MP、條件檢查;付費、標記 `used`、發出 `ability_used`(`zone: "borrowed"`、`via: "E-010"`),以 `slot=None` 執行 handler。不棄卡、不計入使用者的 `used_abilities`。`register_slot_hook` 的 `self_slot` 在借用時為 None,搭檔效果都不使用它。
- 快照的作用中效果公開 `used` 與該卡的 `ability`(時機等),前端據此顯示入口。

### 「次の効果の、片方または両方を、好きな順で」(E-021)

- 兩段 `Choose(EffectOptions(...))`:第一段列出可用的效果(回復需有負傷魔物);第二段排除已選的效果並加「不使用」,沒有其他可用效果時不問。依 `Bound` 分支執行選到的效果。決策種類 `pick_effect`。

### 非戰鬥戰術的使用條件

- `reg.spell_nonbattle(number, effect=..., when=...)` 的 `when` 存在 `reg.SPELL_NONBATTLE_CONDITION`,介面與事件卡的 `when` 相同(`fn(game, player)`)。引擎在支付前檢查,不成立拒絕 `spell.condition`;快照的 `condition_ok` 用同一個函式。
- 需要選擇對象的非戰鬥戰術以「選得到對象」為條件:S-048(場上 M-028、魔書 M-027)、S-043(`RobnosTransformMode` 只列可完整執行的模式)。

## 行為決定與理由

以下「相關規格」除非另外註明,皆指 `card-effects` › 需求「第二彈 68 種卡全數可用」下的情境。修改相關卡片前先看這裡;要改變 `Confirmed` 或 `Project Decision` 的決定,須先與專案負責人確認。

### E-001 在使用時選擇魔物

**相關規格:** `effect-tree` › 需求「Standby 節點跨回合續體與時效」 › 情境「E-001 於下回合開始階段觸發」;`effect-tree` › 需求「延遲效果重新檢查目標」

**決定:** 使用 E-001 時就選擇魔物,下回合開始階段才 +3000;選定的魔物在那之前離場時無效果,不改選其他魔物。

**理由:** 效果文「次のターンのスタートフェイズまで【スタンバイ】し…自分の魔物1体を選ぶ」可以讀成使用時選,也可以讀成開始階段效果解決時才選;規則書沒有定義待命效果的選擇時點。

**依據:**
- E-001 效果文
- 專案負責人決定

**確認狀態:** `Project Decision`

### 「〇〇の術」以使用戰術的魔物判定

**相關規格:** 情境「「〇〇の術」以使用戰術的魔物判定」

**決定:** P-001、P-005、P-007、M-008 的「〇〇の術」以使用戰術的魔物判定,不看戰術卡上的對應魔物;不限使用對象的指令戰術由該魔物使用時也適用。

**理由:** 「スギナの術」可以讀成「スギナ對應的戰術卡」或「スギナ使用的戰術」,效果文不足以唯一決定。

**依據:**
- P-001、P-005、P-007、M-008 效果文
- 專案負責人決定

**確認狀態:** `Project Decision`

### 「このターン中の次のバトル」只作用於下一場

**相關規格:** 情境「「このターン中の次のバトル」只作用於下一場戰鬥」

**決定:** P-001、P-007、M-008、S-019、S-026 的效果只作用於本回合的下一場戰鬥;條件不符時隨該戰鬥結束而消失,不留到之後的戰鬥。

**理由:** 字面是「本回合的下一場戰鬥」,不是「下一場符合條件的戰鬥」。

**依據:**
- 各卡效果文

**確認狀態:** `Confirmed`

### 無戰術攻擊也算「次のバトル」

**相關規格:** 情境「S-026 的不可防禦適用於無戰術攻擊」

**決定:** 無戰術攻擊(M-027)的戰鬥也是「下一場戰鬥」:S-019 / S-026 的「相手は防御できない」適用;P-001 限「ガッシュ・ベルの術で攻撃するとき」,不適用,效果隨該戰鬥結束。

**理由:** 無戰術攻擊走完整的戰鬥流程,是一場戰鬥;S-019 / S-026 的效果不限定用戰術攻擊。

**依據:**
- S-019、S-026、P-001 效果文
- `game-engine` › 需求「無戰術攻擊」

**確認狀態:** `Inferred`

### M-008 在宣告戰術時選擇是否減費

**相關規格:** 情境「M-008 減費由玩家選擇」

**決定:** 在下一場戰鬥宣告スギナ的戰術(攻擊或防禦)時,由該玩家選擇「少付 1 MP,該戰術魔力 -1000」或「不使用」。

**理由:** 效果文為「1低いコストで使うことができる。そうしたなら…」,是否減費在使用戰術的時點決定。

**依據:**
- M-008 效果文

**確認狀態:** `Confirmed`

### M-008 的詢問細節

**相關規格:** 情境「M-008 減費由玩家選擇」

**決定:** 只付得起減費後的費用時直接使用、不詢問;「本来のコスト」已是 0(P-005、最後一頁、指令戰術)時無法「1低いコスト」,不詢問也不減魔力;逾時預設不使用。

**理由:** 付不起原價時「不使用」不是可行的選擇;本來費用為 0 時無法再低 1,也就沒有「そうしたなら」的魔力 -1000;逾時沿用「可選效果預設不使用」的慣例,且只有付得起原價時才會詢問。

**依據:**
- M-008 效果文
- 房間逾時代打的既有慣例(`online-room`)

**確認狀態:** `Inferred`

### S-026 / S-057 擲出正面時不詢問是否使用

**相關規格:** 情境「S-026 / S-057 擲出正面時不詢問是否使用」

**決定:** 「オモテなら、次の効果を使える」擲出正面時直接設置待命,不詢問是否使用。

**理由:** 宣告使用卡片時就已表示意願,且整張卡只有這一個效果。

**依據:**
- S-026、S-057 效果文
- 專案負責人決定(已寫入 AGENTS.md 的「〜できる」規則)

**確認狀態:** `Project Decision`

### 「自分の魔本をめくる/もどす効果を合計1回」計入 E-005

**相關規格:** 情境「E-005 計入「自分の魔本をめくる/もどす」合計1回」

**決定:** E-005 翻 / 回翻自己的魔書也算這類效果,限制卡本身算 1 次。E-005 先翻過就不能用同方向的 P-010 / P-018;先用了 P-010 / P-018,E-005 同方向的結果不發生(E-005 本身仍可使用);反方向不受影響。

**理由:** E-005 的「自分の魔本を2枚もどす / めくる」就是 P-010 / P-018 所指的效果。

**依據:**
- P-010、P-018、E-005 效果文

**確認狀態:** `Confirmed`

**相關規格:** 情境「P-018 在第一頁也能使用」

**決定:** 魔書在第一頁時也能使用 P-018:棄掉卡片、不回翻、不觸發對手 P-019,但仍算本回合唯一一次回翻效果。

**理由:** 效果文沒有限制,與 P-010 在最後一頁也能使用的處理一致。

**依據:**

**相關規格:** 情境「回翻依實際張數」

**決定:** 在第一頁使用 E-005 擲得正正時不回翻,也不算用過「回翻自己魔書」的效果,之後仍可使用 P-018。

**理由:** 沒有發生回翻。P-018 本身則依「限制卡本身算 1 次」另外計算。

**依據:**

### P-013 依魔物卡張數翻頁

**相關規格:** 情境「P-013 依魔物卡張數翻頁」

**決定:** 對手每有 1 張魔物卡入墓翻 1 張:疊兩張的魔物整隻入墓算 2 張、裝甲體單獨入墓算 1 張、P-006 棄掉的頂層與從魔書棄掉的魔物卡也算;搭檔卡、戰術卡不算。

**理由:** 效果文是「相手の魔物カード1枚が捨て札になるたびに」,以卡片張數計。

**依據:**

**確認狀態:** `Confirmed`

### E-018 被限制成減 0 時仍算使用過

**相關規格:** 情境「E-018 減 0 時仍算使用過減少 MP 的效果」

**決定:** E-018 因直前回合的限制而減 0 時,仍算本回合使用過「減少對手 MP」的效果;連續回合使用時,第二次起都減 0。

**理由:** E-018 本身就是減少對手 MP 的效果,使用了就算,與實際減少多少無關(E-004 的註記同樣以「使用」判定)。

**依據:**
- E-018、E-004 效果文

**確認狀態:** `Inferred`

### M-026 還原的範圍

**相關規格:** 情境「M-026 ジャマー於對手使用魔物效果後立即詢問」

**決定:** 還原玩家、modifier、待命與戰鬥內容;對手的費用與「本回合已使用」照算;行動權與戰鬥輪替維持目前的值。效果使戰鬥開始 / 結束或遊戲結束時不提供;搭檔效果、被動效果不觸發。

**理由:** 被無效的是效果,不是使用效果的行動本身,所以費用與使用次數照算;流程狀態還原會讓行動順序錯亂。

**依據:**

**確認狀態:** `Inferred`

**相關規格:** `card-effects` › 需求「M-018 檢視對手頁面並限自己回合」 › 情境「M-018 檢視對手翻開的頁」

### E-021 由玩家選擇效果、順序與回復對象

**相關規格:** `card-effects` › 需求「E-021 選擇效果與順序」

**決定:** 先選第一個效果(回復 / MP +2);選回復時由玩家選負傷魔物;之後詢問是否使用另一個效果,可不使用。沒有負傷魔物時只使用 MP +2。

**理由:** 效果文「片方または両方を、好きな順で使う」「1体を選び」。

**依據:**
- E-021 效果文
- 專案負責人確認

**確認狀態:** `Confirmed`

### E-010 排除被動搭檔、以卡號記錄、離場後仍可使用

**相關規格:** `card-effects` › 需求「E-010 借用對手搭檔效果」
