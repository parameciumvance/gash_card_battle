# battle-ui — 對戰介面

## Purpose

靜態 HTML + 原生 JS,由 FastAPI serve;中文介面。支援本機(hotseat 全視角)、線上(自己在下方、對手翻開頁卡背)與觀戰三種模式。

## Requirements

### Requirement: i18n 字典
UI 的所有顯示文字 SHALL 取自 `i18n/zh-TW.json` key-value 字典(含參數模板),程式碼中 MUST NOT 硬編任何顯示用中文字串;卡片文本取自 `data/cards.zh-TW.json`。新增語言 SHALL 只需新增字典檔。

#### Scenario: 文字全走字典
- **WHEN** 檢查前端程式碼
- **THEN** 顯示文字均經 t(key, params) 取得,無硬編中文字串

### Requirement: 盤面呈現
UI SHALL 呈現:雙方魔本當前對頁、雙方場區(魔物及所裝夥伴、健康直放/負傷橫放)、雙方 MP、當前階段與行動權指示、戰鬥子狀態(攻防宣告內容、合計魔力)。線上模式 MUST 以「自己在下方」呈現(依 token 對應的玩家翻轉視角);對手翻開頁 MUST 渲染為卡背+頁碼(內容不可知);觀戰視角雙方翻開頁皆為卡背。本機模式 SHALL 維持全視角(固定玩家 1 在下)。

#### Scenario: 負傷魔物橫放顯示
- **WHEN** 場上魔物進入負傷狀態
- **THEN** 該卡以橫放(旋轉)樣式呈現

#### Scenario: 戰鬥中顯示合計魔力
- **WHEN** 攻防雙方皆已宣告
- **THEN** 畫面顯示雙方當前合計魔力(含 modifier)並隨戰鬥中效果即時更新

#### Scenario: 線上模式自己在下方
- **WHEN** 以玩家 1(player index 1)的 token 進入線上對局
- **THEN** 自己的場區與魔本渲染在畫面下方,對手在上方

#### Scenario: 對手翻開頁為卡背
- **WHEN** 線上模式渲染對手的翻開對頁
- **THEN** 顯示卡背與頁碼,無卡名/費用/效果文


### Requirement: 卡圖與文字卡面
卡片元件 SHALL 一律先渲染文字卡面(卡名、費用、A/D、魔力、傷害、效果文中譯);對應卡圖檔存在時 SHALL 疊加顯示,並提供懸停/點擊放大檢視完整卡片資訊。

#### Scenario: 卡圖缺失時可玩
- **WHEN** 某卡無卡圖檔
- **THEN** 該卡以文字卡面正常顯示與操作,不出現破圖

### Requirement: 行動記錄
UI SHALL 將事件流以 i18n 模板渲染為中文行動記錄,依時間序顯示並自動捲動;記錄 MUST 涵蓋翻頁、MP 變化、放卡、效果啟動、硬幣結果、戰鬥結果、傷害與勝敗。

#### Scenario: 事件渲染為中文記錄
- **WHEN** 發生 CoinFlipped(正面)事件
- **THEN** 記錄區出現如「擲硬幣:正面」的中文條目

### Requirement: 操作與決策互動
UI SHALL 只提供當下合法的操作(依狀態快照過濾);引擎要求決策時 MUST 以對話框呈現選項,並標明是哪位玩家決策。線上模式 MUST 只啟用自己身分的行動按鈕,對手回合顯示等待指示;決策對話框僅在自己是決策者時展開(否則顯示「對手決策中」)。本機模式 SHALL 維持雙方按鈕並明確標示當前輪到哪位玩家。

#### Scenario: 非法操作不可點
- **WHEN** MP 不足以支付某術的費用
- **THEN** 該術的攻擊宣告按鈕呈禁用狀態並顯示原因

#### Scenario: 庇護對話框
- **WHEN** 引擎發出庇護決策要求且自己是受傷方
- **THEN** 畫面彈出對話框列出可庇護的魔物與「不庇護」選項

#### Scenario: 線上模式不能替對手操作
- **WHEN** 線上模式輪到對手行動
- **THEN** 自己畫面上無任何可提交對手行動的控制項,顯示等待指示

### Requirement: 首頁入口
UI SHALL 提供首頁入口:本機對戰(即開即玩,等同 v1)、建立房間(選擇計時選項,顯示房號/加入連結/觀戰連結供分享)、加入房間(輸入房號或經 join_url 直達)、**牌組構築(開啟構築器視圖)**。本機、建房與加入流程 SHALL 提供牌組選擇(level1 預組 + 本機儲存的合法牌組;不合法牌組顯示為禁用),缺省為 level1。進入對局後 URL SHALL 可直接分享重入(token 存於本機)。

#### Scenario: 建房並分享
- **WHEN** 玩家選擇建立房間(timer=60)
- **THEN** 顯示房號與加入/觀戰連結,並停留於等待對手畫面

#### Scenario: 經連結加入
- **WHEN** 對手開啟 join_url
- **THEN** 自動加入該房,雙方畫面同時進入對局

#### Scenario: 開局時選用自訂牌組
- **WHEN** 玩家在建房面板從牌組選單選擇自己儲存的合法牌組後建房
- **THEN** 該牌組隨建房請求送出,開局後自己的魔本為所選內容

#### Scenario: 不合法牌組不可選
- **WHEN** 牌組選單中存在標記不合法的牌組
- **THEN** 該選項呈禁用狀態並提示需先在構築器修正


### Requirement: 連線狀態與計時顯示
線上模式 UI SHALL 顯示:WS 連線狀態(連線中/重連中,重連成功後自動對齊狀態)、房間計時器的剩餘秒數倒數(依伺服器期限推算,純顯示);逾時代打發生時 SHALL 於行動記錄標示。

#### Scenario: 斷線自動重連
- **WHEN** WS 連線中斷
- **THEN** 顯示重連中,重連成功後畫面與 log 自動補齊,無重複條目

#### Scenario: 倒數顯示
- **WHEN** 房間計時 60 秒且輪到自己行動
- **THEN** 畫面顯示剩餘秒數;逾時後行動記錄出現帶逾時標記的代打條目
