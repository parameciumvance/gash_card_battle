# Spec Delta

## ADDED Requirements

### Requirement: 資訊列的干擾標籤
有干擾(ジャマー)效果圖示的卡(卡片資料的效果圖示含 `jammer`,包括有多個效果圖示的卡)SHALL 在文字卡面的資訊列顯示「干擾」標籤(依目前語言),樣式比照「中級」「上級」標籤;一張卡只顯示一個。沒有干擾圖示的卡 MUST NOT 顯示此標籤。盤面卡面照舊不顯示資訊列(見「文字卡面與卡圖」)。

#### Scenario: 干擾卡的放大檢視
- **WHEN** 使用者開啟 M-026 的放大檢視
- **THEN** 資訊列有「干擾」標籤

#### Scenario: 有多個效果圖示的卡
- **WHEN** 使用者在構築器卡池看 M-080(《乱入》為干擾、《バトル乱入》為 BATTLE)
- **THEN** 資訊列有一個「干擾」標籤

#### Scenario: 一般卡沒有標籤
- **WHEN** 使用者開啟 M-001 的放大檢視
- **THEN** 資訊列沒有「干擾」標籤
