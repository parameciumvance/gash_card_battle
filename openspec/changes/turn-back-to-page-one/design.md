# Design

## Decisions

### D1:回翻的下限是第 1 頁(`pos = 0`)

- 魔書對頁:第 1 頁單獨(左邊封面內側)、2–3……30–31、第 32 頁單獨。`pos` 是對頁左頁的頁碼,第 1 頁的對頁為 `pos = 0`(`open_pages` 只取 1–32 的頁,第 0 頁自然不存在)。
- `turn_back_pages` 的可回翻張數由 `(pos - 2) // 2` 改為 `pos // 2`。開局翻開第 2、3 頁不變;只有效果回翻能到 `pos = 0`。
- 依據:規則書「めくった1枚(2ページ)」與效果文「1枚もどす」都沒有其他下限;原本的下限沒有出處,是把「最多回到第一頁」讀成第一個兩頁對頁。使用者回報即為決定(2026-11-13)。
- 已確認不受影響:開始階段與結束階段翻頁(`pos += 2`)、`maxFlips`、魔書耗盡判定、NPC 評估;前端魔書區與網格原本就把第 0 頁畫成空位、以 `Math.max(pos, 1)` 捲動。
- 第 1 頁的起始魔物在開局就已上場,回到第 1 頁通常沒有可用的卡;E-033 / M-025 / S-146 放回空頁的卡可能放在第 1 頁,那時就能使用。

### D2:既有測試的「第一頁」

- `test_level2.py`(P-019 依實際張數、P-018 在第一頁)、`test_cards.py`(E-005)、`test_season3_effects_4.py`(P-041)原本以 `pos = 2` 當第一頁。依新的下限改為 `pos = 0`,行為決定(回翻 0 張不算用過、不觸發)不變;E-005 在第 2、3 頁擲得正正改為回翻 1 張。

### D3:金手指的目前頁摘要

- 原本一律寫「第 pos、pos+1 頁」,在 `pos = 0` 會出現第 0 頁、在第 32 頁會出現第 33 頁(後者是既有問題)。只翻開一頁時改用 `ui.cheat.current_page`。
