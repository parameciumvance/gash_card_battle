# Design

## Decisions

### D1:防禦時機的入口

- 行動欄的 `defense` 分支在「不防禦」之後,依快照的 `any_page_spells` 篩出防 / 攻防圖示的攻防戰術,有的話加一顆按鈕開魔書網格(與攻擊時相同的文字)。網格與卡片選單原本就會依防禦時機提供「防禦」按鈕(`pageButtons` 的 defenseStep),不需更動。
- 可用與否仍由快照決定(引擎的 `_spell_any_page_standby`);前端只依卡片圖示過濾掉不能防禦的,避免出現點進去沒有可按按鈕的入口。
- (由 D2 取代。)

### D2:改為通用規則(使用者 2026-11-13 決定)

- 盤點其他受影響的卡:P-025 的ジオルク(攻防圖示的非戰鬥戰術)、P-037 / Ex-037 的防 / 攻防圖示事件卡,會在對手回合的非戰鬥中或確認進入戰鬥時插入的行動使用,同樣沒有入口。逐一補時機容易再漏,改成通用規則。
- 行動欄在開始階段以外,把 `any_page_spells` 中 `anyPageButtons(p, e)` 有未停用按鈕的卡算作可用;有的話放一顆按鈕開魔書網格,數量也只計這些。判斷與網格卡片選單完全相同(`pageButtons`),所以入口出現時點進去一定有可按的按鈕,反過來選單能用時入口一定在。
- 代價:回合玩家非戰鬥中,其他頁的卡全都停用(例如 MP 不足)時不再顯示入口(原本會顯示,點進去只看得到停用的按鈕與原因)。翻開的頁仍以停用按鈕呈現原因;魔書網格也仍可從魔書區開啟查看。
- 開始階段不放入口:那時只能翻頁,所有卡都不能使用。
