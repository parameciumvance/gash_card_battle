## ADDED Requirements

### Requirement: 以效果結束戰鬥階段
「このバトルフェイズを終了する」(M-077)SHALL 在效果解決、且干擾的詢問結束後,結束目前的戰鬥階段並進入結束階段;效果被干擾無效時戰鬥階段照常繼續。「このターンのエンドフェイズは…『ページをめくってMPを2ふやす』処理はおこなわない」SHALL 作用於使用當下的回合,不論是誰的回合;結束階段的其他效果照常解決。

#### Scenario: 在對手回合使用
- **WHEN** 對手的戰鬥階段,玩家使用 M-077,對手沒有使用干擾
- **THEN** 進入對手的結束階段,對手不翻魔書、MP 不增加

### Requirement: 被對手的效果翻頁的紀錄
引擎 SHALL 記錄每位玩家本回合被對手傷害以外的效果實際翻過的張數(回合結束歸零);傷害造成的翻頁、被擋下沒有翻的不算。

#### Scenario: 傷害不算
- **WHEN** 玩家的魔書這回合只因傷害翻頁
- **THEN** 被對手的效果翻頁的張數為 0
