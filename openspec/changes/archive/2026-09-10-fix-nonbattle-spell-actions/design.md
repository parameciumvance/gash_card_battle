## Context

pageButtons 目前依 type=spell 與 A/AD 產生攻擊按鈕，未依 effect_icon 排除 nonbattle；spellUsable 使用舊字串 Command: All 識別指示術，但資料與引擎 COMMAND_ALL 已使用 コマンド。引擎的 use_book_card 已支援非對戰術、費用、時機與同卡號每回合限用，S-026 等既有測試可通過。玩家狀態已有 used_nonbattle_spells，但 _player_view 未輸出。

cardEl 已建立 .cnum；一般樣式將其定位在卡面右上角、字體 9px。詳情需明確呈現卡號，不只是新增重複 DOM。

## Goals / Non-Goals

**Goals:**

- 非對戰術可從詳情按「使用」，正確顯示常見禁用原因，正常執行既有效果。
- 前端識別指示術與後端一致；使用紀錄可隨快照重繪與重連恢復。
- 詳情以可辨讀的獨立文字顯示卡號，涵蓋有圖、缺圖、桌面與窄螢幕。

**Non-Goals:**

- 不改寫非對戰術效果、使用次數規則或新增術卡。
- 不全面重構合法行動 API，也不擴充卡池編輯功能。
- 不變更一般戰鬥術的攻擊／防禦名稱或事件卡本身的使用規則。

## Decisions

### 1. 依效果圖示分流，不以卡號特判

pageButtons 對 effect_icon=nonbattle 的術建立「使用」操作並送 use_book_card。攻擊／防禦選項產生處及共用攻防可用性判定皆排除非對戰術，避免在防禦流程仍出現錯誤入口。一般戰鬥術維持原有 declare_attack／declare_defense。按鈕文字共用事件卡的「使用」語意，避免新增「使用術」文案。

### 2. 非對戰使用條件與戰鬥施術分開

非對戰術入口限可控制該玩家、有行動權、一般非戰鬥行動窗口，沒有 battle、battle_in 或 pending。窗口外不提供可操作入口；窗口內依 A/D/AD 回合時機、對應魔物、快照中的實際 entry.cost 與 MP、同卡號使用紀錄判定，禁用時顯示明確原因。指示術不要求特定家族魔物，非對戰指示術也不經 pickSlotThen 選攻擊者。一般指示術攻防仍沿用原本的選施術魔物流程。

將指示術識別集中為使用目前 コマンド 值的輔助判定，套用到此次涉及的前端術卡分支，避免修正非對戰入口後一般指示術仍被誤判。其他特殊術相容性維持引擎最終裁決，實作時核對既有相容性判定，避免前端新增比引擎更嚴格的限制。相較只改 S-026 的按鈕，圖示分流可同步修正五張非對戰術。

### 3. 快照新增持有者使用紀錄

_player_view 在 can_see_player(viewer, p) 時回傳 used_nonbattle_spells，內容為引擎集合排序後的卡號陣列；本機全視角含雙方，線上只含本人，其他視角不含該欄位。雖然使用事件可能公開卡號，本次不擴大隱藏資訊輸出範圍。

前端以卡號而非頁碼判定已使用，同卡不同頁一樣禁用。回合重置以引擎快照為準，不在前端自行計算回合或維護第二份紀錄。新增欄位向後相容，前端缺欄位時以空陣列讀取，伺服器仍拒絕非法重用。相較只在送出成功後本機記憶，快照能支援重連。

### 4. 詳情卡號使用獨立文字版面

在 #zoom-card 範圍調整既有 .cnum 呈現，使用正常排版、至少 14px 字體及清楚對比，在卡片詳情內容最底下以一般字重呈現「S-026」，不加「卡號：」前綴。不依賴圖片內的小字，避免與卡名／卡圖重疊；其他小卡面維持原佈局。以 textContent 顯示實際卡號，純展示詳情也適用；隱藏卡背沒有可見卡號時不推測或揭露。

## Risks / Trade-offs

- [前後端使用條件分歧] → 以引擎為準，驗證回合時機、費用、對應魔物、同卡號重用與指示術；保留後端錯誤回饋。
- [只修攻擊入口，防禦仍錯誤] → 非對戰術在攻防兩側皆排除，回歸一般術及指示術。
- [紀錄洩漏其他視角資訊] → 測試本人、對手、觀戰、本機四種快照可見性。
- [卡號被卡圖覆蓋或窄螢幕截斷] → 詳情採獨立文字行，在有圖、缺圖與窄螢幕實際檢查。

## Migration Plan

部署新增快照欄位與前端更新，不需資料遷移。既有 API 客戶端可忽略新增欄位；回退前端時後端欄位仍可保留。封存前同步 battle-ui 與 battle-api delta 回主規格。
