## Context

動機見 proposal.md。第 1、2 彈的繁中當初依英文資源翻譯。英文效果文後來依日文重譯(card-data design「卡片文字檔」),但沒有逐張複核。第 3 彈與第 3 賽季的繁中是依日文翻譯的，這次直接沿用它們的用語慣例。

魔物卡已在 2026-10-31 的 explore 中逐張對照。繁中的偏差(proposal 所列)與實作的差異，都已經和使用者確認：實作差異之後另開 change 處理，這次只改文字。

## Goals / Non-Goals

**Goals:**
- 135 張的繁中效果文改成日文直譯，用語與第 3 彈之後的譯文一致。
- 英文效果文的偏差改成直譯。
- 簡中隨之重新產生。

**Non-Goals:**
- 卡名、戰術名、效果名:使用者已比照代理版譯名校對過，不改(2026-10-31)。
- 英文 `name` / `attr`(取自 TTS 卡表，依 card-data 規格不改)。
- 第 1、2 彈以外的卡，只改 D3 的固定句型。
- 遊戲行為。翻譯時發現的實作差異記在 `implementation-diffs.md`,不在這次修正。

## Decisions

### D1 直譯的原則

- 逐句對應日文：條件、對象、次數、時效、選擇者都照日文。不補日文沒有的說明，也不省略日文有的措辭。要特別注意的措辭:
  - 「1個」「1枚」「1体」「1つ」;
  - 「選び」(選擇);
  - 「できる」(可以);
  - 「本来」(原本的);
  - 「この順で」(依序);
  - 「（0より小さくはならない）」等括號註記。
- 主詞照日文:「自分が」→「自己」,「この魔物が」→「此魔物」,「相手は」→「對手」。
- 卡片規則文字(《效果名》以外的文字，例如「自分の『ゴフレ』に重ねる。」)也直譯，不改寫成說明。

### D2 用語對照(沿用第 3 彈之後的譯文)

| 日文 | 繁中 |
|---|---|
| MPをNへらす→ | 【MP減少N→】 |
| 使用を宣言する→ | 【宣告使用→】 |
| このカードを捨て札にする→ | 【將此卡棄掉→】 |
| このカードが場にある→ | 【此卡在場上→】 |
| 【ステイ】/【スタンバイ】/【反撃】 | 【持續】/【待命】/【反擊】 |
| 魔本 / 術 / 術カード | 魔書 / 戰術 / 戰術卡 |
| 「魔物の効果」 | 「魔物的效果」 |
| 場に出す | 放到場上 |
| 捨て札にする / 捨て札 | 棄掉 / 棄牌區 |
| 負傷状態 / 健康状態 | 負傷狀態 / 健康狀態 |
| かばう | 保護 |
| コインを投げてオモテなら | 擲硬幣:正面時 |
| ゲーム中に1回だけ使える | 此效果一場遊戲只能使用1次 |
| このターン中の次のバトルで | 本回合的下一場戰鬥中 |

- 「」括起的卡名、戰術名:換成該卡的繁中 `name`,保留「」。

### D3 戰術卡的固定句型(使用者 2026-10-31 確認)

- 目前全部的繁中，都把「相手の魔本にダメージ。」譯成「以攻擊方獲勝時,對對手的魔書造成傷害。」,共 40 多張;【反擊】與「無効にする」也有類似的寫法。這些都補上了規則說明「以攻擊方 / 防禦方獲勝時」,不是直譯。
- 英文是直譯的「Damage to your opponent's Spell Book.」。
- 依 D1 應該改成「對對手的魔書造成傷害。」,規則說明交給規則頁。但這是全部卡共用的句型，只改第 1、2 彈會造成前後不一致。
- 決定：這三種固定句型(「相手の魔本にダメージ。」、【反撃】、「相手の攻撃を無効にする」類)在**全部卡片**一起改成直譯，規則說明交給規則頁。其餘句子只改第 1、2 彈。

### D4 做法

- 以腳本在 scratchpad 列出每張卡的日文、現行繁中、現行英文。由我逐張寫直譯，寫回 `data/cards.zh-TW.json` / `cards.en.json`,並保留 JSON 格式與鍵的順序。
- 完成後產生對照表(日文 / 舊繁中 / 新繁中 / 英文變更),供使用者抽查。
- 翻譯時發現的實作差異，記在本 change 的 `implementation-diffs.md`。魔物卡的差異已經決定，一併記入，供之後的實作 change 使用。

## Risks / Trade-offs

- 譯文變長或句型改變後，前端版面(卡片放大、行動記錄)可能需要換行。相關瀏覽器測試涵蓋。
- 測試若寫死了舊譯文會失敗，依新譯文更新。
