## MODIFIED Requirements

### Requirement: 意見回報
UI SHALL 提供意見回報對話框,可從首頁的「意見回報」入口與頂欄的「回報」按鈕開啟(對局內外皆可)。對話框 SHALL 列出回報管道:
- **回報表單**(已設定表單網址時):不需要帳號;連結 SHALL 以預填網址帶入環境資訊。未設定表單網址時 MUST NOT 顯示此管道。
- **GitHub issue**:標示需要 GitHub 帳號,連到 repo 的新 issue 選擇頁。

外部連結 SHALL 在新分頁開啟。對話框 SHALL 顯示同一份環境資訊並提供複製按鈕。

環境資訊 SHALL 為一行固定格式、不翻譯的文字,包含語言、版本號(`GET /api/meta` 的 `version`)與瀏覽器;在對局中另含模式、房號、回合數與階段。環境資訊 MUST NOT 含 token、暱稱或牌組內容。

開啟與關閉對話框 MUST NOT 影響對局(指令、計時與推送照常)。

#### Scenario: 從首頁開啟意見回報
- **WHEN** 玩家在首頁點「意見回報」
- **THEN** 開啟對話框,列出回報表單與 GitHub issue 兩個管道,GitHub 管道標示需要帳號;關閉後回到首頁

#### Scenario: 表單連結預填環境資訊
- **WHEN** 對局中(NPC 對戰,第 3 回合)玩家點頂欄「回報」
- **THEN** 回報表單的連結帶有預填的環境資訊,內容含語言、版本號、`mode=npc`、房號、`turn=3`、階段與瀏覽器,不含 token 與暱稱;對話框顯示同一份文字

#### Scenario: 未設定表單
- **WHEN** 表單網址未設定,玩家開啟意見回報
- **THEN** 只顯示 GitHub issue 管道與環境資訊

#### Scenario: 對局中回報不影響對局
- **WHEN** 對局中玩家開啟意見回報後關閉
- **THEN** 回到原畫面;期間對手的行動照常推送、計時照常

### Requirement: 首頁免責聲明
首頁 SHALL 在入口下方顯示免責聲明,說明:本網站為非官方粉絲專案,與原作者及 BANDAI 無關、未經授權;免費且不涉商業行為;作品與卡片相關權利屬於雷句誠、BANDAI 及各權利人;權利人如有疑慮可透過意見回報聯絡。文字 SHALL 取自 i18n 字典,依目前語言顯示;提到意見回報時 SHALL 使用與首頁入口相同的名稱,但不做成連結。免責聲明 MUST NOT 是按鈕或入口,也 MUST NOT 遮住入口。免責聲明下方 SHALL 顯示版本號(`GET /api/meta` 的 `version`)。

#### Scenario: 首頁顯示免責聲明
- **WHEN** 玩家以中文開啟首頁
- **THEN** 入口下方顯示「非官方粉絲專案,與原作者及 BANDAI 無關,亦未經授權;免費且不涉商業行為。」與「作品與卡片相關權利屬於雷句誠、BANDAI 及各權利人;權利人如有疑慮,請透過「意見回報」聯絡。」,其中「意見回報」不是連結

#### Scenario: 離開首頁後不顯示
- **WHEN** 玩家從首頁進入 NPC 對戰設定頁
- **THEN** 免責聲明隨首頁一起隱藏

#### Scenario: 首頁顯示版本號
- **WHEN** 服務的版本號為 `v0.9.1`,玩家開啟首頁
- **THEN** 免責聲明下方顯示「版本 v0.9.1」
