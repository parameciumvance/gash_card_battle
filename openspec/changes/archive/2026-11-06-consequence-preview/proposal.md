# Proposal

## Why

新手試玩回饋(todo「新手評論 8–10」)都指向同一件事:資訊透明度已經進步,下一步是從「現在的數值」延伸到「按下去會發生什麼」。

- **保護的後果**:雪莉(P-012)生效時選健康的蒂歐保護,只看到「選擇」,不知道她保護後會直接被棄掉;已負傷的凱喬美再次保護也沒有離場警告。兩位試玩者都把這項列為最優先,第二位還在新版重現了同一個情境。
- **翻頁的代價**:開始階段翻頁時,不知道翻了之後本回合結束會因無頁可翻而落敗;現在要翻到最後一對頁之後才出現警告,已經來不及。
- **預估合計魔力少了確定的加成**:S-092 ザケルガ預估 8000,攻擊時實際 10000(「この術を攻撃で使ったとき、この術の魔力を+2000する」)。這正好影響賈修的不可防禦門檻,而這個加成在宣告前就能確定。

使用者決定只提示會離場或可能敗北的後果,不列「之後將無法使用的戰術」等延伸資訊。

## What Changes

- **保護的後果預告**:保護決策中,保護後會被棄掉的魔物,在卡片行動選單的「選擇」上方與寬螢幕的詳情面板顯示警告,並寫出原因(已負傷,或來源卡如「雪莉 P-012」)。結果由引擎以實際的結算判定,取決於擲硬幣或之後的選擇時不提示。只會負傷或不受傷害時不提示。
- **翻頁的落敗預告**:開始階段的翻頁按鈕,翻了之後本回合結束時會因無頁可翻而落敗的,按鈕旁加註「翻頁後,本回合結束時將因無頁可翻而落敗」。
- **預估合計魔力加上確定的宣告時加成**:戰術自身「攻擊 / 防禦時」與依公開狀態的條件加成(S-016、S-017、S-092、Ex-043)算進預估,明細列出;擲硬幣的加成仍不算。附註改為「不含擲硬幣與戰鬥中的效果」。
- 四種語言。

不保護時魔書會耗盡的提示已經存在(battle-ui「保護決策顯示傷害」),不重複。

## Capabilities

### New Capabilities

(無)

### Modified Capabilities

- `battle-api`:新增「保護的後果預告快照」「翻頁後落敗的快照」;修改「戰術的預估合計魔力快照」(算進確定的宣告時加成)。
- `battle-ui`:新增「保護的後果提示」「翻頁按鈕的落敗提示」;修改「戰術的預估合計魔力」(附註文字)。

## Impact

- 引擎:`src/gash/engine/engine.py`(保護後果的判定、`end_flip_loses` 推廣到翻 N 張之後、預估魔力的宣告時加成),可能沿用 `npc/settle.py` 的 `clone`。
- API:`src/gash/api/views.py` 快照欄位。
- 前端:`frontend/app.js`(卡片行動選單、詳情面板、翻頁按鈕、預估魔力附註)、`frontend/style.css`、`frontend/i18n/*.json`(四語)。
- 測試:引擎 / API 測試與瀏覽器測試。
- 不改規則與卡片效果本身。
