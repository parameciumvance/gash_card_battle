# deck-builder — 手機直向上下分割(delta)

## MODIFIED Requirements

### Requirement: 對頁編輯
構築器 SHALL 以 16 個對頁(P1 首頁與 P32 末頁單獨呈現)網格呈現魔本,並提供卡池瀏覽(67 張,可依類型/對應魔物/收錄產品篩選;同一張卡可屬多個產品)。**寬螢幕(>700px)為左右兩欄(卡池|魔本);窄螢幕(≤700px,手機直向)SHALL 改為上下分割:上半為魔本對頁網格(縮小卡面、獨立捲動)、下半為卡池(篩選器收合為一列、卡池網格獨立捲動),即時合法性提示恆可見。** 玩家 SHALL 可:點選卡池的卡放入選中頁位(或下一個空頁)、點選頁位移除卡片、以拖拉(或點選兩頁位)互換兩頁位的卡片;**窄螢幕以點選互動為準,拖拉為寬螢幕增強**。編輯中 MUST 允許空頁與違規狀態存在。

#### Scenario: 放卡與移除
- **WHEN** 玩家在卡池點選 S-001 且第 3 頁為空
- **THEN** S-001 進入第 3 頁;再點選第 3 頁可將其移除

#### Scenario: 頁位互換
- **WHEN** 玩家將第 5 頁的卡拖到第 12 頁(或依序點選兩頁位)
- **THEN** 兩頁位的卡片(含空頁)互換

#### Scenario: 依產品篩選卡池
- **WHEN** 玩家在產品篩選選擇「The Best Booster 1」
- **THEN** 卡池只顯示收錄於該產品的卡,可再與類型篩選複合

#### Scenario: 手機上下分割構築
- **WHEN** 於 ≤700px 寬的直向視窗開啟構築器
- **THEN** 魔本對頁網格在上、卡池在下,各自獨立捲動;點卡池的卡放入選中頁,合法性提示保持可見

#### Scenario: 手機篩選收合
- **WHEN** 於窄螢幕展開篩選列
- **THEN** 類型/對應魔物/產品篩選以精簡形式(下拉)呈現並可複合,不長期佔用卡池空間
