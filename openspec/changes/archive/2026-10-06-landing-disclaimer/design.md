## Decisions

### D1:位置與呈現

- 放在首頁(`#landing`)入口下方的頁尾 `#landing-disclaimer`,小字、低對比,不搶入口的視線。
- 只在首頁顯示。對局、構築器、設定頁不顯示,避免佔用手機畫面。
- 文字取自 i18n(`ui.landing.disclaimer_fan`、`ui.landing.disclaimer_rights`),兩句各一行。

### D2:措辭

依目的寫成兩句(與使用者討論後定稿,用短版):

1. **非官方**:明說與原作者及 BANDAI 無關、未經授權(沒有取得任何許可)。「粉絲專案」本身不足以避免被誤認為官方。另說明免費、不涉商業行為。
2. **權利歸屬與聯絡**:權利人不只雷句誠與 BANDAI(漫畫的小學館、動畫的東映動畫與富士電視台等),逐一列出容易遺漏或寫錯官方標示,所以寫「雷句誠、BANDAI 及各權利人」。附上聯絡方式(意見回報),權利人有疑慮時找得到人。

- 日文是權利人會看的版本,用日文慣用的說法(「非公式のファンプロジェクト」「一切関係ありません」「許諾」),不逐字翻譯。
- 「意見回報」以參數 `{feedback}` 帶入首頁入口的名稱(`ui.landing.feedback`),各語言名稱一致;依使用者決定不做成連結。

### D3:README

README 開頭放同樣的中文聲明,讓從 GitHub 看到 repo 的人也看得到;聯絡方式改指向 GitHub issue 與遊戲內的「意見回報」。
