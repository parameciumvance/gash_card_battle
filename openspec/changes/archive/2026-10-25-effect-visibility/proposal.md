# Proposal

## Why

常駐效果與作用中效果生效時不夠醒目:P-013 因魔物入墓翻對手魔書時,聚焦演出只有一行併在「魔物入墓」格裡的文字,沒有卡圖,玩家沒有發現;M-031 擋下傷害只寫「傷害被防止」,不知道是誰擋的。持續生效的數值(M-003 / M-014 的魔力加成、M-040 的費用 +1 等)只顯示最後數字,看不出被改過、也看不出原因。

## What Changes

- **觸發時的卡片聚焦**:非宣告型效果(常駐效果的觸發、傷害免疫、待命 / ステイ在某個時點生效、戰鬥後的附加效果)造成可見結果時,聚焦演出以該效果的來源卡另起一個卡片格(卡圖、卡名、效果文與結果行),雙方都顯示,不受「自己發起的行動只顯示不利結果」的過濾。來源卡與目前卡片格相同時(例如使用的事件卡自己的效果)維持併在同一格。
- **事件補上來源**:`damage_prevented` 補 `source`(M-031 等免疫、M-013 / M-015 等不受傷害、S-037 等全體免疫、S-079 的保護);行動記錄寫出來源卡。傷害被防止、無效、MP 增減被擋下這幾種事件也納入文字聚焦。
- **數值分色**:場上魔物的魔力、翻開的戰術 / 事件頁的費用與卡面不同時,依對持有者有利或不利著色(魔力高於卡面、費用低於卡面為有利綠色;反之為不利紅色)。
- **數值明細**:快照的魔物附魔力明細,翻開的戰術 / 事件頁附費用明細;放大檢視顯示明細(來源卡與加減值),格式同對決時的戰力明細。費用明細為新增的計算(卡面、最後一頁(ADV)、本来のコスト為 0、待命的費用加減、M-040)。
- **常駐效果失效中的標示**:場上魔物或搭檔的常駐效果正被「使えない」擋下時,快照標出失效的卡與造成限制的來源卡;場上卡片顯示「失效」標記,放大檢視列出失效的效果與原因。出場時的效果(已解決)不列。
- **一次性時點被擋下的記錄與聚焦**:出場時、入墓時、開始階段的常駐效果,以及傷害免疫,在該時點被擋下時發出事件;記錄寫出「《卡》的效果被《來源》擋下」,聚焦以該卡另起卡片格。觸發型常駐效果(P-013 / P-019 / P-030 / M-028)被擋下時不發事件,由失效標示呈現。

## Capabilities

### New Capabilities

(無)

### Modified Capabilities

- `battle-api`:魔物槽的 `power_breakdown`、失效中的常駐效果;翻開頁的 `cost_breakdown`;`damage_prevented` 事件的 `source`;新事件 `effect_blocked`。
- `battle-ui`:聚焦展示加上效果來源卡格;魔力 / 費用分色;放大檢視的數值明細與失效中的效果;場上的失效標記;傷害被防止與效果被擋下的記錄。

## Impact

- `src/gash/engine/engine.py`:費用明細(`spell_cost` / `event_cost` 改由明細算出)、`damage_prevented` 的 `source`、限制來源的查詢、`effect_blocked` 事件;`effects/primitives.py` 的 `run_on_play`。
- `src/gash/api/views.py`:`_slot_view`、`_player_view`。
- `frontend/anim.js`(聚焦時間軸)、`frontend/app.js`(`cardEl` 的數值、放大檢視、記錄)、`frontend/style.css`、i18n。
- 測試:引擎 / 快照測試、瀏覽器測試(聚焦、分色、明細)。
