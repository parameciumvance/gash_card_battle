## Goals / Non-Goals

**Goals:**
- 7 張全部依效果文實作並開放，每張非香草卡至少一個依效果文寫的行為測試。

**Non-Goals:**
- Ex-025、M-065、Ex-034(下一批，需要「對手使用增減 MP 的效果或事件卡後立即回應」的機制)與 M-058(最後一批)。
- 改變既有卡的行為。

## Decisions

### D1 擲硬幣子階段的重擲與改成正面

- `reg.coin_reflip(number, coins=, mp_cost=0, per_turn=1)`:Ex-026 為 `mp_cost=1, per_turn=2`。使用次數以 `used_abilities` 的 `"mamodo:{卡號}"` 計(第 2 次起 `#2`,`uses_this_turn`),與啟動效果共用「每回合」的計法。MP 不足時不提供。
- 擲幣者的選項依來源卡分開(M-012 免費、Ex-026 付 MP):選項都附 `card`(與 `mp`)供前端顯示來源。為了不改動既有的決策值,M-012 類(免費、每回合 1 次)維持「第幾枚」的數字、M-034 維持 `"heads:{i}"`;新增的來源帶卡號(`"reflip:Ex-026:0"`、`"heads:P-039:0"`)。實作時原本打算統一格式,但會改動 18 個既有測試的決策值,改為相容寫法。
- `reg.coin_set_heads` 支援搭檔卡:場上魔物的搭檔在 `COIN_SET_HEADS` 時也列入，受「不能使用搭檔的效果」限制;使用時棄掉這張搭檔(費用)。

### D2 從任意頁使用的待命

- `spell_any_page` 待命的 data 擴充:
  - `mamodo`:指定名稱的戰術(M-037 已有),依「『〇〇の術』的判定」以 `spell_names` 判斷(對應魔物或使用的魔物的名稱);P-037 為「ブラゴ」,不限頁範圍但 `exclude_last=True`。
  - `events=True`:也允許事件卡(P-037);事件卡的每回合張數、自分 / 相手のターン與使用條件照常檢查。
  - `event_page` + `cost_delta`:Ex-037 使用時選定的那一頁事件卡，本來費用 +1。
  - `attack_only` + `next_battle`:PR-006 只允許下一場戰鬥的攻擊戰術(任何戰術)。
- 一張待命合計 1 次:從翻開的頁以外使用時消耗待命。P-037 的戰術與事件卡共用同一個待命。
- 事件卡從非翻開頁使用：`_use_book_card` 的 `any_page` 判斷加入事件卡;費用加上 `cost_delta`(`event_cost_breakdown` 的明細)。
- 快照的 `any_page_spells` 也列出事件卡(費用含 Ex-037 的 +1,明細種類 `any_page_cost`)與非戰鬥戰術的使用條件;前端從魔書使用的按鈕改為沿用翻開的頁的按鈕(攻擊、事件卡、非戰鬥戰術)。
- Ex-037 選擇魔書中的事件卡:新增決策種類 `pick_event_in_own_book`(四語標題)。

### D3 PR-001 的費用 0

- `PR-001` 宣告使用(`per_game=True`)→ 待命 `spell_free_once`(owner、`mamodo` = 宣告時 PR-001 的名稱、`max_cost=3`,本回合)。
- 「この魔物の術」:依「『〇〇の術』的判定」,`mamodo` 在 `spell_names(card, 使用的魔物)` 中即符合;PR-001 離場後仍依名稱作用,另一隻ガッシュ・ベル使用的、或其他魔物使用的ガッシュ・ベル的戰術(M-029 的「ザケル」)也適用(使用者 2026-10-31)。
- 「コスト3まで」:宣告時的實際費用(`spell_cost`,含其他效果的增減),不含追加費用(S-067 / S-097 的 `extra_cost`)。「コスト0」:費用歸 0,追加費用照付。依據是 atwiki Ex-007 卡頁引用的 Ex-011 裁定「追加でふやすコストは０にはなりません」;判斷用的費用與歸 0 的費用是同一個數字。目前有追加費用的戰術只有エシュロス / ティオ的,ガッシュ・ベル用不到,規則先寫明供之後的卡使用。
- 宣告戰術時:符合條件且待命存在時,在 M-008 的減費詢問之後、追加費用之前詢問(`_ask_spell_free`;新增決策種類 `spell_free` 與四語標題「是否以費用 0 使用此戰術?(追加費用照付)」,來源卡為 PR-001,選項標籤 `spell_free_use`。原本打算沿用 `spell_discount`,但它的標題是 M-008《策士》專用的說明,本機抽查時使用者發現 PR-001 顯示成 M-008 的文字,改為新種類)。選擇使用 → 費用歸 0、在支付時移除待命;不使用 → 保留。付不起原價時直接使用(同 M-008)。
- 「術1つ」也包含非戰鬥戰術(PR-009 為ガッシュ・ベル的非戰鬥戰術,ガッシュ・ベル使用的指令戰術也算):使用非戰鬥戰術時同樣詢問,決定後重新執行使用(`_ask_free_nonbattle`)。

### D4 PR-006 的加成

- 指令戰術(`spell_nonbattle`)→ 待命 `spell_any_page`(`attack_only`、`next_battle`)與下一場戰鬥的加成待命(同 S-057 的 `next_battle` 待命):該場戰鬥的攻擊戰術魔力 +3000、傷害 +1(【ステイ】,`DUR_BATTLE`)。
- 攻擊戰術不論來自翻開的頁或其他頁都加成(使用者 2026-10-31);魔物效果攻擊沒有加成，待命隨該場戰鬥結束。

### D5 P-041 的觸發

- `reg.trigger("P-041", "pages_turned", ...)`:事件的 `player` 是對手、`count < 0`(實際回翻)、來源是效果(`source` 不是規則翻頁)時觸發。回翻 0 張時 `turn_back_pages` 不發事件，所以不觸發(使用者 2026-10-31:同 E-005 / P-019,回翻 0 張不算用過回翻效果)。
- 觸發後由持有者 `Choose(EffectOptions(魔書傷害, 魔物傷害))`;對手沒有魔物時只剩魔書傷害(自動)。魔物傷害再 `Choose(OpponentMamodo)`。兩者都走一般傷害管線(可保護)。
- 觸發器在 `emit` 中同步執行,不能在對手的效果中途建立決策(會與對手效果的決策互相覆蓋)。所以觸發時只排定待命 `deferred`(`DeferOnOpponentTurnBack`),`engine.submit` 在每個指令處理完、沒有待決事項也沒有待詢問的ジャマー時,依序執行這些效果(`reg.deferred` 登記,`_run_deferred_effects`)。對手的效果被ジャマー無效而還原狀態時,待命隨之消失。
- `reg.action_discard("P-041", "partner")`。

## Risks / Trade-offs

- [M-012 的擲幣選項值格式改變] → 前端選項對應與既有測試一併更新。
- [事件卡從非翻開頁使用是新路徑] → 測試涵蓋每回合張數、使用時機與費用 +1。
