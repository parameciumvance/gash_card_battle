# Design

## Decisions

- 附註沿用 `addBtn` 的兩行按鈕(按鈕名稱 + 小字附註),只在「不翻頁」(張數 0)且最多可翻張數 > 0 時加;最多可翻張數與行動欄既有的計算相同(`min(3, floor((32 - pos) / 2))`)。
- 發光:`renderBookBlock` 產生「›」時,開始階段、該魔書屬於回合玩家且自己能操作、沒有 pending、目前翻閱位置與目前頁相差的張數小於最多可翻張數時,加 `.flip-glow`。翻閱到上限時自然消失;不能翻頁時最多可翻張數為 0,不發光。
- 樣式:脈動的外框光暈;`prefers-reduced-motion` 或演出設定的減少動畫時改為靜態外框(沿用既有的減少動畫判斷)。
- 不改既有的「依翻閱位置選張數」流程(使用者決定維持)。
