## Context

窄螢幕(≤700px)的 `#layout` 為直欄,`#log-panel` 是底部抽屜:收合時以 `#log { display: none }` 隱藏,頁籤(`#log-title`)顯示最新一條;展開時 `flex: 0 0 45vh`。

查閱魔本(`showBookReview`)每次都清空並重建網格;開啟期間每次 `render()` 也會重呼叫它,讓可選頁隨狀態更新。

## Decisions

### D1:展開時的高度與捲動

- 原因:`#log-panel` 與 `#log` 是 flex 子項,`min-height` 預設為內容高度,`flex-basis: 45vh` 擋不住內容,面板被撐高、盤面被擠成 0 高,捲動的是整頁而不是 `#log`,所以 `scrollTop = scrollHeight` 沒有作用。
- 修正:`#log-panel.open` 與 `#log` 加 `min-height: 0`,面板固定 45vh,記錄在 `#log` 內捲動。展開時、新增記錄時捲到最底(沿用既有程式)。

### D2:收合時顯示最新 4 條

- 純 CSS:收合時 `#log` 照常顯示,但只顯示最後 4 條(`.ev:not(:nth-last-child(-n+4))` 隱藏),每條單行、過長以省略號截斷,高度固定約 4 行,不會隨記錄內容忽高忽低擠動盤面。
- 頁籤只顯示「行動記錄」,不再重複最新一條。
- 收合時記錄中的卡名仍可點開檢視;展開 / 收合仍點頁籤。
- 寬螢幕側欄不變。

### D3:查閱魔本開啟時捲到當前頁

- 只在「開啟」時捲動(`BOOK_VIEW` 從未開啟或換了玩家):把當前翻開的對頁捲到面板上緣附近。
- 開啟期間的重繪先記下 `#book-review` 的 `scrollTop`,重建網格後還原,不打斷玩家正在看的位置。
- 決策目標在魔本中(書內搜卡、檢視對手魔本)時同樣捲到當前翻開的頁;可選頁仍以發光標示。
- 當前頁已全部離開魔本(兩頁都已上場或使用)時,仍以 `pos` 所在的對頁為準。
- 開啟時就捲到中段,原本在網格上方的標題與「關閉」會被捲走:`#book-review-head` 改為 sticky 固定在面板上緣,捲動位置扣掉它的高度。
