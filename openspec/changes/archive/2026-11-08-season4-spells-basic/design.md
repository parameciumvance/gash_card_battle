# Design

## Context

27 張戰術的日文效果文與 A/D 欄已逐張對照既有卡(見 proposal)。防禦戰術的效果用 `on_effects_end`(defense-effects-timing)。攻擊的擲幣、選對象在宣告時確定(game-engine「戰鬥流程五步驟」)。

## Goals / Non-Goals

**Goals:** 27 張依效果文可用,每張非香草卡至少一個行為測試。

**Non-Goals:** 其餘 66 張第 4 賽季卡(之後的批次)。

## Decisions

### D1:沿用既有寫法的卡

| 卡 | A/D | 寫法 |
|---|---|---|
| S-116 | A | 同 Ex-015:獲勝時「次のターンのエンドフェイズまで、相手は『魔物の効果』や術を使えない」 |
| S-141 | AD | 同 S-009:造成傷害時對手到下一回合結束不能用戰術(防禦時不造成傷害,自然不觸發) |
| Ex-068 | AD | 同 S-016:防禦時此戰術魔力 +2000 |
| S-142 | A | 同 S-082:攻擊宣告時擲幣,正面傷害 +1(效果文先寫擲幣、後寫傷害,結果相同) |
| S-134 | AD | 合計魔力固定 7000(攻防都是,`fixed_total`,同 S-087);攻擊時擲幣同 S-082 |
| S-120 / Ex-065 | D | 宣告時擲 2 次;至少 1 次正面時,於「効果の使用」的最後使攻擊無效 |
| S-139 / Ex-064 | D | 於「効果の使用」的最後使這場攻擊的傷害 -2 / -1(不論魔力勝負) |
| S-130 | AD | 防禦時同 S-139(傷害 -2);攻擊時是一般的魔書傷害 3 |

### D2:新節點與欄位

- **S-132**:`on_win` 在造成傷害前,以條件 `OpponentDidNotDefend` 判斷,成立時 `IncreaseThisSpellDamage(1)`。「防御していなければ」= 這場戰鬥防禦方沒有宣告防禦(戰術或魔物效果);宣告了防禦、之後被無效,仍算有防禦(使用者 2026-11-08 選擇)。
- **S-137 / Ex-050**:`IncreaseThisSpellDamagePerHeads(per_head=1)`,依 `ctx["results"]` 的正面數加傷害(兩張的資料傷害都是「?」,基礎 0)。S-137 只在攻擊時擲幣(傷害只在攻擊成功時有用,比照 S-082);Ex-050 只能攻擊,另以 `AddSpellPowerPerHeads(1000)` 加魔力。正面 0 次時攻擊成功也不造成傷害(沒有「ダメージをあたえたとき」)。
- **S-143**:`SpellRider.power_per_count = (計數規格, 每單位魔力)`,`side_breakdown` 在計算這個戰術的魔力時加入一項「計數 × 2000」;計數規格 `OwnDiscardMamodoCards` = 使用者棄牌區的魔物卡張數。魔力勝負時計算(使用者 2026-11-08 選擇),宣告前的預估也用當下的值。攻防都適用。
- **S-115**:攻擊宣告時先記下「沒有選定的魔物」,擲 1 次;正面時由攻擊方選對手 1 隻魔物記下(`RememberDeclaredTarget`;對手沒有魔物時沒有對象)。獲勝時沿用 `DamageOpponentBookAndAllMamodo`:對魔書造成此戰術傷害,再對選定且仍在場的魔物造成傷害(依效果文順序;實際承受順序依規則由受方決定,沿用引擎)。擲幣在宣告時(使用者 2026-11-08 選擇)。魔物傷害不以「魔書受到傷害」為條件(atwiki 卡頁解說)。S-057 待命:效果文含「相手の魔本にダメージ」,魔書傷害改為對 S-057 選定的魔物造成傷害,擲幣的魔物傷害不變。
- **S-118**:比照 S-070,攻擊宣告時由攻擊方二選一;選「搭檔」時一併選對手 1 張搭檔(`OpponentPartneredMamodo(discard=True)`,M-049 保護的除外;沒有可選的搭檔時只有魔書)。獲勝時依選擇:魔書傷害,或棄掉選定的搭檔、不造成傷害(`DiscardRememberedPartner`)。選擇時已明確選了對象,S-057 不改變(`chooses_damage_target`)。新選項標籤 `discard_partner`。

## Risks / Trade-offs

- [S-143 的魔力在戰鬥中可能變動] → 依效果文「になる」持續計算;明細照實顯示。
- [S-115 與 S-057 的組合] → 有測試鎖定。
