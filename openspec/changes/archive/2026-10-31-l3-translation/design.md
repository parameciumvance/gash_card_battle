## Decisions

### D1 直譯原則

沿用 l12-translation D1:逐句對應日文，主詞、條件、次數、時效、選擇者照日文，不補不省。

### D2 固定譯法(全部卡片共用)

l12-translation D2 的對照表，加上:

| 日文 | 繁中 |
|---|---|
| この効果は、…(とき / なら / ば)使える | 此效果在…時可以使用 |
| 次の効果の1つを使う | 使用以下效果的其中1個 |
| 次の効果の両方を使う | 使用以下兩個效果 |
| 次の効果の両方を、この順で使う | 依序使用以下兩個效果 |
| 次の効果の、片方または両方を、この順で使う | 依序使用以下效果的其中1個或2個 |
| そうしたなら | 這麼做時 |
| N枚めくる / もどす | 翻 / 回翻…N張 |
| 好きなページ | 任意頁 |
| 〜を選び、場に出す / 捨て札にする | 選擇…,放到場上 / 棄掉 |
| この効果は、次のターンのスタートフェイズまで【スタンバイ】し、次のターン中【ステイ】する | 此效果在下回合的開始階段之前【待命】,在下回合中【持續】(同 E-001) |
| 術 / 術カード | 戰術 / 戰術卡(依日文區分) |
| 「X」(卡名、戰術名) | 「X 的繁中名稱」 |

- 「」只在日文有「」時加,日文有就保留(與第 1、2 彈一致):卡名、戰術名換成繁中名稱;「かばう」「健康状態」「負傷状態」等譯成「保護」「健康狀態」「負傷狀態」;「ステイ」「スタンバイ」譯成「持續」「待命」。
- 以腳本先套用機械式的句型替換，再逐張人工檢查;意思出入的卡逐張重寫。

### D3 英文

逐張對照 `effect_ja` 與 `cards.en.json`。英文沒有固定譯法的對照表，只修正意思出入(主詞、條件、可選、次數、句子順序)。

### D4 做法

沿用 l12-translation D4:scratchpad 腳本列出日文 / 繁中 / 英文，寫回 JSON 時保留格式(`indent=1`、結尾換行)與鍵的順序;完成後產生對照表供使用者抽查。

## Risks / Trade-offs

- [機械式替換改錯句子] → 替換後逐張人工檢查，對照表列出每張的新舊譯文。
- [寫死舊譯文的測試失敗] → 依新譯文更新。
