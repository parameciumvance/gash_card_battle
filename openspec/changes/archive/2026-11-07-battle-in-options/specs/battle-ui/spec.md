# Spec Delta

## ADDED Requirements

### Requirement: 進入戰鬥確認的用語與提示
UI 的用語 SHALL 依規則書的「バトル・インの確認」與「バトル・イン」:步驟名稱為繁中「進入戰鬥確認」、日文「バトル・インの確認」、英文「Battle-in check」;非回合玩家回應的按鈕為繁中「同意進入戰鬥」、日文「バトル・インを認める」、英文「Allow battle-in」;回合玩家使用攻擊效果進入戰鬥為繁中「進入戰鬥」、日文「バトル・イン」、英文「Battle in」。行動記錄、對決舞台的提示、詳細提示、錯誤訊息與規則頁 SHALL 使用同一套用語。對決舞台的提示 SHALL 說明可以同意進入戰鬥並在下一步宣告防禦,或使用其他行動讓這次確認無效。過去的更新內容不改。四種語言都有對應文字。

#### Scenario: 按鈕與提示
- **WHEN** 對手宣告攻擊,等待自己回應進入戰鬥確認
- **THEN** 行動欄只有「同意進入戰鬥」一個回應按鈕;對決舞台提示可以同意進入戰鬥、在下一步宣告防禦,或用其他行動讓確認無效

#### Scenario: 行動記錄
- **WHEN** 對手以「ザケル」宣告攻擊,自己同意進入戰鬥
- **THEN** 行動記錄為「{對手} 以《ザケル》進行進入戰鬥確認」與「進入戰鬥!{對手} 以《ザケル》攻擊」

#### Scenario: 日文用語
- **WHEN** 介面為日文
- **THEN** 按鈕為「バトル・インを認める」,步驟名稱為「バトル・インの確認」

## MODIFIED Requirements

### Requirement: 行動選項附註
行動欄的 Pass 與同意進入戰鬥按鈕 SHALL 在按鈕內以兩行呈現:上行為按鈕名稱,下行以較小的字附註此刻這個選項的意思。
- 非戰鬥中,輪到回合玩家:「Pass」/「不進行自己回合行動」。
- 非戰鬥中,輪到非回合玩家:「Pass」/「不進行對手回合行動」。
- 戰鬥效果步驟:「Pass」/「不使用戰鬥中效果」。
- 進入戰鬥確認:「同意進入戰鬥」/「接著宣告防禦;或插入行動使確認無效」。

防禦宣告的「不防禦」按鈕維持原樣,沒有附註。行動欄的選項按鈕 SHALL 與行動欄底色有明顯對比;「展開提示」SHALL 以和行動選項不同的樣式呈現。附註 SHALL 依語言設定顯示。

#### Scenario: 自己回合的 Pass 附註
- **WHEN** 自己的回合非戰鬥中輪到自己
- **THEN** 行動欄的 Pass 按鈕下行顯示「不進行自己回合行動」

#### Scenario: 對手回合的 Pass 附註
- **WHEN** 對手的回合非戰鬥中輪到自己
- **THEN** 行動欄的 Pass 按鈕下行顯示「不進行對手回合行動」

#### Scenario: 戰鬥中效果的 Pass 附註
- **WHEN** 戰鬥效果步驟輪到自己使用戰鬥中效果
- **THEN** 行動欄的 Pass 按鈕下行顯示「不使用戰鬥中效果」

#### Scenario: 迎戰附註
- **WHEN** 對手宣告攻擊,等待自己回應進入戰鬥確認
- **THEN** 行動欄的按鈕上行為「同意進入戰鬥」、下行顯示「接著宣告防禦;或插入行動使確認無效」;防禦宣告時的「不防禦」沒有附註
