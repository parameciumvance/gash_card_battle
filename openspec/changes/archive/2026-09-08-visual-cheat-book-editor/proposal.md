## Why

本機對戰的金手指目前必須手動編輯 32 項卡號 JSON 陣列，難以辨識卡片與頁位，也容易輸入錯誤。改用一般牌組構築器熟悉的卡圖瀏覽與點選操作，讓使用者直接調整測試場面。

## What Changes

- 將金手指 JSON 文字框改為對局內的大型卡圖編輯視窗，提供玩家切換、32 頁魔本與 MP 輸入。
- 點選頁位後從卡池選卡替換，支援類型／魔物／彈數篩選與拖曳交換頁位；再次點選同頁取消選取。
- 雙方修改獨立暫存，切換玩家保留內容，套用時一起送出；提供重新整理與取消，套用失敗保留草稿。
- 保留金手指自由修改的規則：只要求完整 32 頁及有效卡號，不套用一般構築限制。
- 不提供載入預組、已存牌組或整本替換，也不保留手動 JSON 編輯介面。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `battle-ui`: 將金手指面板規格改為逐頁卡圖編輯，定義選牌、篩選、交換、草稿與套用行為。

## Impact

- 前端 `frontend/app.js`、`frontend/index.html`、`frontend/style.css`、`frontend/i18n/zh-TW.json`，以及必要的共用卡池呈現邏輯。
- 沿用既有卡圖與卡片資料，不引入新套件。
- 沿用 `GET/POST /api/rooms/{code}/debug-state`；後端權限、驗證、事件與廣播契約不變。
- 一般牌組構築器的本機儲存與構築驗證保持原有行為。
