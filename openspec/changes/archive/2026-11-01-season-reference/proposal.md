# Proposal

## Why

房間、牌桌與魔書都依賽季驗證(card-data「賽季定義」),但畫面上只看得到「第 N 賽季起」這個結果,查不到每個賽季可用哪些卡號、收錄哪些產品。玩家選賽季或構築時無從判斷某張卡能不能用。範圍定義在 `data/seasons.json`,前後端已經共用。

## What Changes

- 規則頁新增「賽季」段落:說明文字(一張卡屬於最早包含它的賽季、魔書的賽季取決於最新的卡、房間選定賽季後雙方魔書都依此驗證)寫在四語內容檔;各賽季的卡號範圍與新增的產品由新的動態區塊 `{"seasons": true}` 依 `seasons.json` 與卡片資料畫出,補卡或調整範圍時不用改內容檔。不可選的賽季(目前 Ex-000 屬第 4 賽季)另外註明。
- 設定頁(NPC 對戰、與朋友對戰的建立模式、本機)與牌桌頁開桌設定的賽季選單旁加上連結,開啟規則頁的賽季段落。
- 構築器魔書名稱旁的「第 N 賽季起」可以點,開啟規則頁的賽季段落。

- 附帶修正:構築器的賽季標示改用深色背景(原本在淺色標題列上看不清);日文的回報對話框標題與首頁入口改為「ご意見・報告」,與頂欄按鈕「報告」一致。

- 「第 N 賽季起」的標示(構築器、牌組選單)改為「第 N 賽季起可用」(使用者要求,四語),意思較清楚。

## Capabilities

### New Capabilities

(無)

### Modified Capabilities

- `battle-ui`:新增「規則頁的賽季段落」;「設定頁的賽季選單」加上連到賽季段落的連結;「牌組選單依賽季」的標示改為「第 N 賽季起可用」。
- `deck-builder`:「魔書的賽季標示」可點開規則頁的賽季段落,文字改為「第 N 賽季起可用」。

## Impact

- 前端:`frontend/app.js`(規則頁區塊渲染、賽季選單旁連結、構築器賽季標示)、`frontend/style.css`、`frontend/index.html`。
- 內容:`frontend/i18n/rules.{zh-TW,en,ja}.json` 新增段落與表格標籤(簡中由 `tools/build_zh_cn.py` 產生);連結的提示文字用介面字典(四語)。
- 不改伺服器與 `seasons.json` 格式。
