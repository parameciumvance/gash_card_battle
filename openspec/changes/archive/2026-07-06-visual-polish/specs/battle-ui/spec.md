# battle-ui — 差分:鏡像牌桌、MP token 與事件動畫

純前端視覺強化:佈局重構為鏡像牌桌、MP 圓形 token、事件驅動動畫層。資訊視角規則不變。

## MODIFIED Requirements

### Requirement: 盤面呈現
UI SHALL 以鏡像牌桌呈現:雙方魔物列隔中線(對決舞台)相對,搭檔列位於各自魔物列的己方外側並與魔物同欄垂直配對(固定 3 欄含空欄虛框,搭檔欄與魔物欄同高、搭檔卡與魔物卡同尺寸);魔本區(對頁+MP 托盤)置於外角——對手右上、我方左下對角相對,與場區同一橫帶以壓低全場高度。所有框格(魔物欄、搭檔欄、對頁頁位、MP 托盤、盤面卡片)MUST 為固定尺寸,不因有無卡片或按鈕而伸縮。魔本對頁 MUST 恆為兩個頁位:卡片仍在則呈現卡面(對手視角=卡背+頁碼),卡片已離開頁面(上場/使用)則該頁位顯示壓暗卡背,超出書末為空位。雙方 MP SHALL 以圓形 token 呈現於魔本前方(朝中線側)的托盤,魔本區 MUST NOT 與場區重疊(1 顆=1 MP,滿 16 顆後折疊為「●×N」,並保留數字標示)。仍須呈現:健康直放/負傷橫放、當前階段與行動權指示、戰鬥子狀態(攻防宣告內容、合計魔力,呈現於對決舞台)。線上模式 MUST 以「自己在下方」呈現(依 token 對應的玩家翻轉視角);對手翻開頁 MUST 渲染為卡背+頁碼(內容不可知);觀戰視角雙方翻開頁皆為卡背。本機模式 SHALL 維持全視角(固定玩家 1 在下)。

#### Scenario: 對角佈局
- **WHEN** 進入任一對局
- **THEN** 對手魔本區在右上角、我方魔本區在左下角;對手搭檔列在其魔物列之上、我方搭檔列在其魔物列之下;雙方魔物列隔中線相對

#### Scenario: 搭檔垂直配對
- **WHEN** 我方魔物裝有搭檔卡
- **THEN** 搭檔卡顯示於該魔物同一欄的下方槽位;未裝備的魔物欄顯示空搭檔虛框

#### Scenario: 框格固定尺寸
- **WHEN** 任一欄位放上或移除卡片、卡片按鈕出現或消失
- **THEN** 魔物欄/搭檔欄/對頁頁位/MP 托盤的尺寸不變

#### Scenario: 卡片離開頁面後顯示卡背
- **WHEN** 魔本頁上的卡片被放出至場上或使用
- **THEN** 該頁位顯示壓暗卡背,對頁仍維持兩個頁位

#### Scenario: MP token 呈現與折疊
- **WHEN** 玩家 MP 為 6
- **THEN** 托盤顯示 6 顆圓形 token;MP 為 20 時折疊為「●×20」樣式

#### Scenario: 負傷魔物橫放顯示
- **WHEN** 場上魔物進入負傷狀態
- **THEN** 該卡以橫放(旋轉)樣式呈現

#### Scenario: 戰鬥中顯示合計魔力
- **WHEN** 攻防雙方皆已宣告
- **THEN** 對決舞台顯示雙方當前合計魔力(含 modifier)並隨戰鬥中效果即時更新

#### Scenario: 線上模式自己在下方
- **WHEN** 以玩家 1(player index 1)的 token 進入線上對局
- **THEN** 自己的場區與魔本渲染在畫面下方,對手在上方

#### Scenario: 對手翻開頁為卡背
- **WHEN** 線上模式渲染對手的翻開對頁
- **THEN** 顯示卡背與頁碼,無卡名/費用/效果文

## ADDED Requirements

### Requirement: 事件動畫
UI SHALL 以事件流驅動動畫,本機指令回應與 WS 推送(對手行動、觀戰)走同一管線。疊加式動畫(翻頁 3D 書頁、卡片自魔本飛入場上、MP token 增減、負傷/棄牌演出)MUST NOT 阻塞盤面更新;阻塞式動畫(魔力對決演出、3D 擲硬幣)SHALL 短暫延後重繪(500–800ms,含硬性逾時保底後強制重繪)。`prefers-reduced-motion` 生效時 MUST 跳過全部動畫直接呈現最終狀態。動畫 MUST NOT 影響指令提交與計時(裁決在伺服器)。

#### Scenario: 翻頁動畫
- **WHEN** 任一方魔本頁前進(主動翻頁或受傷)
- **THEN** 該方對頁以書頁翻轉動畫過渡;一次翻多頁時錯開演出對應次數(上限 4);受傷造成的翻頁帶紅色閃光區別

#### Scenario: 魔力對決演出
- **WHEN** 收到 showdown 事件
- **THEN** 對決舞台演出攻防合計數字與勝負結果後,盤面才更新至結算後狀態

#### Scenario: 擲硬幣演出
- **WHEN** 收到 coin_flipped 事件(非開局決定先攻)
- **THEN** 畫面中央播放 3D 硬幣旋轉並落定於正/反面

#### Scenario: 對手行動同樣有動畫
- **WHEN** 線上模式經 WS 收到對手的翻頁與出卡事件
- **THEN** 己方畫面播放相同的翻頁與飛卡動畫

#### Scenario: reduced-motion 退場
- **WHEN** 作業系統設定減少動態效果
- **THEN** 所有動畫跳過,狀態變化直接呈現,對局流程完全可用
