## Why

功能已齊(對戰/線上/構築)但呈現仍是工程原型:場區橫排讀不出魔物與搭檔的對應、佈局不像牌桌、MP 只是數字、所有狀態變化瞬間跳變沒有過程感。這款遊戲的高潮 — 翻魔本、詠唱術、魔力勝負、硬幣判定 — 值得被「演」出來,而既有的事件流架構讓動畫可以零後端改動地掛上去。

## What Changes

- **鏡像牌桌佈局**:對手區(上)由上而下=魔本對頁→搭檔→魔物;中線為對決舞台;我方區(下)=魔物→搭檔→魔本對頁。魔物與搭檔改為垂直配對欄位(每魔物一欄,搭檔槽固定在魔本側,空槽也顯示)。
- **MP 圓形 token**:MP 以一顆顆圓形 token 呈現於魔本旁托盤,超過兩排折疊為「●×N」;增減時 token 飛入/飛出。
- **事件驅動動畫層**(新前端模組):以既有事件流為觸發器 —
  - 疊加式(不阻塞):翻頁 3D 書頁(傷害翻頁帶紅閃)、卡片從魔本飛入場上、MP token 增減。
  - 阻塞式(500–800ms):魔力對決(攻防術卡滑向中線、數字滾動至合計、勝負演出)、3D 擲硬幣。
  - 本機操作與 WS 推送(對手行動、觀戰)走同一條動畫管線;`prefers-reduced-motion` 時全部跳過直接呈現結果。
- **魔本主題視覺**:深色桌墊質感、紅金書皮框住魔本對頁、中線發光、卡片 hover 浮起陰影。
- 純前端變更:引擎、API、資訊視角、i18n 架構全部不動;構築器沿用新視覺語彙但互動不變。

(無)

## Impact

- 受影響程式碼:`frontend/style.css`(大改)、`frontend/app.js`(渲染結構重排 + 動畫掛鉤)、新增 `frontend/anim.js`(動畫模組)、`frontend/index.html`(區塊結構)。
- 不影響:`src/gash/`(引擎與 API)、`data/`、既有 115 個後端測試。
- 新增相依:無(CSS transition/animation + 原生 JS)。
