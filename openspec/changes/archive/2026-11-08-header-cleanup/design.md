## Context

- `renderPlayerZone` 的標題列(`.pz-head`):玩家名稱、「▶ 行動中」(`acting-label`)、MP 數字、魔書進度(`book-progress`,耗盡時「魔書耗盡」)、「查閱魔書」(`review-btn`,有 `ps.book` 時)。
- board-side-zones 之後:MP 托盤自帶「MP N」;魔書頁位下方印「第 N 頁」;行動方有區塊外框(`.player-zone.active`)與行動欄的回合轉盤「行動玩家」;棄牌區入口已移到棄牌區格。

## Goals / Non-Goals

**Goals:** 標題列不重複盤面已有的資訊;查閱魔書的入口在魔書旁。

**Non-Goals:** 行動欄、魔書網格本身。

## Decisions

### D1 拿掉重複資訊,名稱移到中線

- 拿掉行動中標籤、MP、魔書進度、查閱魔書(使用者決定,2026-11-08)。行動權仍有區塊外框;「共 32 頁」不再顯示(魔書固定 32 頁)。`ui.acting_label`、`ui.book_progress` 移除。
- 標題列只剩名稱後,使用者要求把雙方名稱整理到中線省一列:`#battle-stage` 第一列 `#stage-head` =「我方(下方區)名稱|時機指示|對手(上方區)名稱」。左右依雙方魔書所在的角落(我方左下、對手右上);名稱前的 ▼ / ▲ 指向所屬的區;行動方的名稱綠色(與區塊外框同色),所以名稱與區塊仍對得起來。名稱過長時省略。
- 窄螢幕時機指示佔滿一行,名稱放在它上方同一列的兩端,仍比兩個標題列少一列。

### D4 頂欄的對局狀態

逐項評估(使用者同意 2026-11-08):

| 頂欄項目 | 盤面上已有 | 處理 |
|---|---|---|
| 你是 X | 中線名稱的「(你)」 | 拿掉;觀戰的「觀戰中」移到中線 |
| 第 N 回合 | 無(只有回合開始橫幅) | 移到中線,接在時機指示前 |
| 回合玩家 | 回合轉盤的「回合玩家」 | 拿掉 |
| 階段 | 時機指示、回合轉盤中央 | 拿掉 |
| 輪到 X 行動 | 區塊外框、中線名稱、轉盤「行動玩家」 | 拿掉 |
| 等待 X 決策 / 對手決策中 | 區塊外框(決策者) | 行動欄的等待提示(見下) |
| 擲幣結果 | 擲幣動畫、行動記錄;決策者的提示框 | 行動欄的等待提示(見下) |
| 等待防禦宣告 | 對決舞台防禦方的文字 | 拿掉 |
| 對局結束(勝負、原因、NPC 牌組、重新開啟結算) | 無 | 移到中線,取代時機指示 |

- 既有規格「操作與決策互動」(不是決策者時顯示「對手決策中」)與「擲幣重擲詢問顯示目前結果」(等待時在等待提示處看得到目前結果)原本靠頂欄滿足;頂欄拿掉後改在行動欄加 `.waiting-note`,規格行為不變。觀戰者看到「等待 {玩家} 決策」。
- 窄螢幕中線兩行:第一行「▼ 我方|第 N 回合|▲ 對手」(`#stage-mid` 以 `display: contents` 讓回合數與名稱同列),第二行時機指示或終局資訊。
- 移除不再使用的 `ui.you_are`、`ui.acting`。

### D2 查閱魔書在書皮下緣

- 與「回到目前頁」(書皮上緣的小標籤按鈕)相同樣式,放在書皮下緣置中,只在 `bookBrowsable(p)` 時加入(與左右翻閱鍵同條件:快照含持有者完整魔書)。
- 書皮下緣原本印頁碼(`page-no`)在頁位下方、書皮內;按鈕跨在書皮外框上,不蓋住頁碼。

### D3 魔書耗盡顯示在書皮上

- 規格要求顯示「魔書耗盡」;標題列拿掉後改在書皮中央疊一個標籤(`.book-exhausted`),此時兩個頁位都是超出書末的空位,不會遮到卡片。

## Risks / Trade-offs

- [取捨] 名稱離開玩家區,靠左右位置與 ▼ / ▲ 對應。→ 行動方的名稱與區塊外框同色。
- [風險] 書皮下緣的按鈕與我方下方的棄牌區格 / 窄螢幕的魔書列相鄰。→ 截圖確認不重疊。
