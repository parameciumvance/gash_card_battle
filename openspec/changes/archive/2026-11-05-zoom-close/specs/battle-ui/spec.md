# Spec Delta

## ADDED Requirements

### Requirement: 放大檢視的關閉
卡片放大檢視 SHALL 在卡面右上角的外側顯示關閉鈕(「×」;卡面右側放不下的窄螢幕改在卡面右上角的正上方),MUST NOT 蓋到卡面,不隨卡面內容捲動,觸控尺寸至少 44px,四種語言都有「關閉」的無障礙名稱;按下即關閉放大檢視。放大檢視開著時按 Esc SHALL 關閉放大檢視,MUST NOT 同時關閉底下的其他視窗(棄牌區視窗、魔書網格、檢視對手頁面的對話框等),也 MUST NOT 觸發底下畫面的其他 Esc 行為(例如魔書翻閱回到目前頁)。點擊卡面與按鈕以外的背景 SHALL 照舊關閉放大檢視。對局與牌組構築器的放大檢視都適用。

#### Scenario: 按關閉鈕
- **WHEN** 玩家點開一張場上的卡的放大檢視,按卡面右上角旁的「×」
- **THEN** 放大檢視關閉,盤面不變

#### Scenario: 按 Esc 關閉
- **WHEN** 放大檢視開著時按 Esc
- **THEN** 放大檢視關閉

#### Scenario: 只關最上層
- **WHEN** 棄牌區視窗開著,玩家從中開啟某卡的放大檢視後按 Esc
- **THEN** 放大檢視關閉,棄牌區視窗仍開著;再按一次 Esc 才關閉棄牌區視窗

#### Scenario: 點背景仍可關閉
- **WHEN** 放大檢視開著時點卡面與按鈕以外的背景
- **THEN** 放大檢視關閉

#### Scenario: 構築器的詳情
- **WHEN** 牌組構築器中按某卡的「詳情」開啟放大檢視,再按「×」或 Esc
- **THEN** 放大檢視關閉,魔書沒有變動
