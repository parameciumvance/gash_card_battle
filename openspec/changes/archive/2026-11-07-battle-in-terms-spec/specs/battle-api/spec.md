# Spec Delta

## ADDED Requirements

### Requirement: 非回合玩家可用行動的快照
戰鬥階段等待非回合玩家輸入、且沒有進行中的決策時,該玩家視角的快照 SHALL 標示除了預設回應(進入戰鬥確認為同意進入戰鬥、防禦步驟為不防禦、其他為 pass,與逾時代打相同)之外,是否還有其他合法的行動;沒有時 SHALL 附上預設回應的指令。可用行動的判斷 SHALL 由引擎以實際送出的合法性決定,防禦包含戰術與魔物效果的防禦。對手、觀戰者,以及等待回合玩家或有決策時,MUST NOT 含這個欄位。

#### Scenario: 沒有可用行動
- **WHEN** 非戰鬥中輪到非回合玩家,他沒有能放出、使用或啟動的卡
- **THEN** 他的快照標示沒有其他可用行動,並附上 pass 指令

#### Scenario: 進入戰鬥確認可以插入行動
- **WHEN** 進入戰鬥確認時,非回合玩家翻開的頁有可以使用的事件卡
- **THEN** 他的快照標示有其他可用行動,不附自動指令

#### Scenario: 只有魔物效果防禦
- **WHEN** 防禦步驟,非回合玩家沒有可用的防禦戰術,但場上有可用魔物效果防禦的魔物
- **THEN** 快照標示有其他可用行動

#### Scenario: 沒有可用的防禦
- **WHEN** 防禦步驟,非回合玩家沒有任何可用的防禦
- **THEN** 快照標示沒有其他可用行動,並附上不防禦的指令

#### Scenario: 對手看不到
- **WHEN** 等待非回合玩家輸入
- **THEN** 回合玩家與觀戰者的快照沒有這個欄位
