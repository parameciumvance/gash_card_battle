## MODIFIED Requirements

### Requirement: 回合轉盤的 pass 傾斜
非戰鬥中已累積 1 次 pass 時,回合轉盤的「回合玩家」標籤 SHALL 自原位順時鐘繞行 45°,表示再 pass 就結束這個回合,並在轉盤旁固定位置以小字提示再 pass 就換誰的回合,依觀看者稱呼(回合玩家是自己時「已 pass 一次,再 pass 就換對手的回合」,是對手時「已 pass 一次,再 pass 就換你的回合」,本機模式與觀戰以下一位玩家的名稱稱呼);有人行動、pass 次數歸零時 SHALL 轉回原位。換到對手的回合時,標籤 SHALL 沿順時鐘方向轉到對面,MUST NOT 反向轉。戰鬥中的 pass MUST NOT 讓標籤傾斜。提示出現、消失或文字長短改變時,行動欄的選項按鈕 MUST NOT 移動位置(轉盤旁的提示欄寬度固定,文字在欄內換行)。

#### Scenario: 一次 pass 後轉盤傾斜
- **WHEN** 自己的回合非戰鬥中,自己 pass
- **THEN** 「回合玩家」箭頭自指向自己的位置順時鐘繞行 45°,中心為綠底「非戰鬥」,轉盤旁顯示「已 pass 一次,再 pass 就換對手的回合」,「行動玩家」箭頭指向對手;玩家區塊名稱旁沒有回合玩家徽章

#### Scenario: 對手回合 pass 的提示
- **WHEN** 對手的回合非戰鬥中,對手 pass 後輪到自己
- **THEN** 轉盤旁顯示「已 pass 一次,再 pass 就換你的回合」

#### Scenario: 有人行動轉盤轉回
- **WHEN** 轉盤因一次 pass 而傾斜時,對手放了一張卡
- **THEN** 「回合玩家」箭頭轉回指向回合玩家的原位,提示消失

#### Scenario: 再 pass 轉到對面
- **WHEN** 轉盤傾斜時,對手也 pass,進入對手的回合
- **THEN** 「回合玩家」箭頭沿順時鐘方向轉到指向對手的區塊

#### Scenario: 戰鬥中的 pass 不傾斜
- **WHEN** 戰鬥效果步驟中一方 pass
- **THEN** 「回合玩家」箭頭不傾斜、仍指向回合玩家,中心為紅底「戰鬥中」,轉盤在行動欄左端

#### Scenario: 提示不推動選項按鈕
- **WHEN** 非戰鬥中一方 pass,轉盤旁出現「已 pass 一次,再 pass 就換…的回合」
- **THEN** 行動欄的 Pass 按鈕與 pass 之前在同一個水平位置
