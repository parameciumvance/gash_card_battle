# Proposal

## Why

新手試玩回饋(todo「新手評論 2」):賈修的「效果(MP 1)」在非戰鬥時灰掉,按鈕沒有說明原因。檢查後:

- `abilityUsableNow` 在只能戰鬥中 / 只能非戰鬥 / 不是自己的行動 / 不在效果步驟 / 開始階段 / 等待決策時停用,都沒有附原因。
- 效果按鈕、魔物效果攻擊 / 防禦、事件卡的 MP 不足顯示「MP < n」,戰術已是「MP 不足(目前 m,需要 n)」。
- 引擎另外檢查搭檔效果被限制、魔物效果被封鎖、效果的使用條件,快照沒有這些資訊:按鈕看起來能按,按了才被拒。
- 不是自己行動時,翻開頁的卡沒有任何按鈕,看不出為什麼不能用。

## What Changes

- 引擎新增 `ability_block`:場上卡(魔物、搭檔)與借用搭檔效果目前不能使用的原因代碼,判斷與指令相同(搭檔效果失效、魔物效果被封鎖、只能戰鬥中 / 非戰鬥中 / 自己的回合、本回合已用、一場限 1 次、MP 不足、使用條件);指令改用同一個函式。
- 快照:持有者本人視角的魔物槽附 `ability_block` / `partner_ability_block`,玩家附 `borrowed_block`。
- 前端:效果按鈕停用時一律顯示原因;卡本身能用但現在不行時說明時機(輪到你行動時、效果步驟、戰鬥階段、先完成目前的選擇)。MP 不足統一為「MP 不足(目前 m,需要 n)」。
- 翻開頁的卡在現在不能用時,放大檢視顯示主要動作的停用按鈕與原因(放出、使用、攻擊、防禦);可用卡的發光不變。

## Capabilities

### New Capabilities

(無)

### Modified Capabilities

- `battle-api`:新增「效果的使用可否快照」。
- `battle-ui`:修改「卡片放大檢視」(不能用的主要動作以停用按鈕與原因呈現);新增「停用按鈕的原因」。

## Impact

- 引擎 `src/gash/engine/engine.py`、快照 `src/gash/api/views.py`。
- 前端 `frontend/app.js`、`frontend/i18n/*.json`(四語,簡中由工具產生)。
- 測試:引擎 / 快照、瀏覽器(放大檢視的按鈕與原因)。
