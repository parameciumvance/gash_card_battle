# Spec Delta

## ADDED Requirements

### Requirement: 自動 pass
對局畫面的行動欄 SHALL 為對局中的玩家提供「無可用行動時自動 pass」開關(觀戰者不顯示),所有模式預設開啟,記在瀏覽器,對戰中可隨時切換。開啟時,快照標示自己(非回合玩家)沒有其他可用行動並附上預設回應時,UI SHALL 在演出播完後倒數 3 秒自動送出該指令,並在開關旁顯示倒數中。倒數期間玩家仍可自己操作;玩家自己送出回應、關掉開關,或狀態改變時 SHALL 取消倒數;開啟卡片放大檢視或卡片行動選單時 SHALL 暫停,關閉後重新倒數 3 秒。MUST NOT 重複送出。四種語言都有對應文字。

#### Scenario: 沒有可用行動時自動 pass
- **WHEN** 開關開啟,輪到自己(非回合玩家)且快照標示沒有其他可用行動
- **THEN** 約 3 秒後自動送出 pass,行動欄在送出前顯示倒數中

#### Scenario: 查看卡片時暫停
- **WHEN** 倒數中玩家點開一張卡的放大檢視,看了 5 秒後關閉
- **THEN** 檢視開著時沒有送出;關閉後再過約 3 秒才送出

#### Scenario: 自己先按
- **WHEN** 倒數中玩家自己按下 Pass
- **THEN** 只送出一次 pass

#### Scenario: 關閉開關
- **WHEN** 玩家取消勾選「自動 pass」
- **THEN** 不再自動送出,直到再次勾選;設定在重新整理後保留

### Requirement: 有可用行動的提示
快照標示自己(非回合玩家)有其他可用行動時,行動欄 SHALL 提示「有可以使用的效果或行動」,不列出是哪些。四種語言都有對應文字。

#### Scenario: 有可用的效果
- **WHEN** 輪到自己(非回合玩家),場上魔物有可以使用的效果
- **THEN** 行動欄提示有可以使用的效果或行動,不自動 pass
