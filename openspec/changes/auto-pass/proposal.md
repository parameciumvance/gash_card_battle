# Proposal

## Why

非回合玩家能用的行動不多,卻在回合玩家的每個行動之後、每次戰鬥開始確認、每次防禦步驟、效果步驟輪流時都被詢問,大多時候只能一直按 pass。新手回饋(todo「新手評論 10」)也希望一眼看出現在有沒有能做的事,不必逐張點卡確認。

## What Changes

- 引擎判斷等待中的非回合玩家「除了預設回應(pass、進入戰鬥、不防禦)之外,還有沒有其他合法的行動」,只告訴該玩家。
- **自動 pass**:沒有其他可用行動時,等演出播完後倒數 2 秒自動送出預設回應。行動欄的 Pass 旁有「無可用行動時自動 pass」開關,所有模式預設開啟,對戰中可隨時切換(記在瀏覽器);倒數中開啟卡片放大檢視或卡片行動選單時暫停,關閉後重新倒數;玩家自己按下回應或關掉開關時取消。
- **有可用行動的提示**:有其他可用行動時,行動欄提示「有可以使用的效果或行動」,不列出內容。可用的防禦包含戰術與魔物效果的防禦。
- 只限非回合玩家(使用者決定);決策(pending)不自動回應。
- 資訊外洩:自動 pass 讓對手能從回應速度推測是否有可用行動(對手翻開的頁是隱藏的)。使用者知悉後決定所有模式預設開啟,以 2 秒延遲減輕(參考遊戲王 Master Duel 的發動確認也接受同樣的外洩、交給玩家設定)。

## Capabilities

### New Capabilities

(無)

### Modified Capabilities

- `battle-api`:新增「非回合玩家的可用行動快照」。
- `battle-ui`:新增「自動 pass」「有可用行動的提示」。

## Impact

- 引擎 / NPC:沿用 `npc/candidates.py` 的候選列舉與 `npc/settle.py` 的副本試送判斷合法;預設回應沿用 `engine/awaiting.py` 的 `default_command`(逾時代打用的同一個)。
- API:`src/gash/api/views.py` 快照欄位。
- 前端:`frontend/app.js`(行動欄開關、倒數、提示)、`frontend/style.css`、`frontend/i18n/*.json`。
- 測試:引擎 / API 測試與瀏覽器測試。
