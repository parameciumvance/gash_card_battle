## Context

- `renderPlayerZone` 的標題列(`.pz-head`):玩家名稱、「▶ 行動中」(`acting-label`)、MP 數字、魔書進度(`book-progress`,耗盡時「魔書耗盡」)、「查閱魔書」(`review-btn`,有 `ps.book` 時)。
- board-side-zones 之後:MP 托盤自帶「MP N」;魔書頁位下方印「第 N 頁」;行動方有區塊外框(`.player-zone.active`)與行動欄的回合轉盤「行動玩家」;棄牌區入口已移到棄牌區格。

## Goals / Non-Goals

**Goals:** 標題列不重複盤面已有的資訊;查閱魔書的入口在魔書旁。

**Non-Goals:** 玩家名稱的呈現、行動欄、魔書網格本身。

## Decisions

### D1 標題列只留名稱

- 拿掉行動中標籤、MP、魔書進度、查閱魔書(使用者決定,2026-11-08)。行動權仍有區塊外框;「共 32 頁」不再顯示(魔書固定 32 頁)。
- `ui.acting_label`、`ui.book_progress` 不再使用;i18n 有檢查未用鍵的測試時一併移除。

### D2 查閱魔書在書皮下緣

- 與「回到目前頁」(書皮上緣的小標籤按鈕)相同樣式,放在書皮下緣置中,只在 `bookBrowsable(p)` 時加入(與左右翻閱鍵同條件:快照含持有者完整魔書)。
- 書皮下緣原本印頁碼(`page-no`)在頁位下方、書皮內;按鈕跨在書皮外框上,不蓋住頁碼。

### D3 魔書耗盡顯示在書皮上

- 規格要求顯示「魔書耗盡」;標題列拿掉後改在書皮中央疊一個標籤(`.book-exhausted`),此時兩個頁位都是超出書末的空位,不會遮到卡片。

## Risks / Trade-offs

- [取捨] 名稱列變得很空。→ 保留名稱與「(你)」,之後若要加回其他資訊再討論。
- [風險] 書皮下緣的按鈕與我方下方的棄牌區格 / 窄螢幕的魔書列相鄰。→ 截圖確認不重疊。
