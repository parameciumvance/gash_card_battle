## 2. 引擎核心(不含卡片效果)

- [ ] 2.1 定義核心資料模型:GameState、玩家狀態(魔本頁序/當前頁/MP/場區/棄牌區)、魔物槽(卡片堆疊+健康/負傷)、Command/Event 型別、可注入 seed 的 RNG
- [ ] 2.2 實作指令驗證框架與事件輸出:非法指令拒絕+原因碼、合法指令回傳事件列表
- [ ] 2.3 實作準備階段與開始階段:初始盤面、翻頁 0-3 張與 MP、開始階段效果解決點
- [ ] 2.4 實作戰鬥階段輪流行動權(かわりばんこ):行動權轉移、pass、雙 pass 結束階段
- [ ] 2.5 實作放卡行動:魔物(≤3、同名限1)、夥伴(對應魔物、每魔物1張)、疊放魔物(變身後)
- [ ] 2.6 實作場上效果啟動框架:宣告使用/MP減少/棄卡啟動/常在,每回合一次限制、禁搭便車規則
- [ ] 2.7 實作魔本中卡片使用:事件卡(每回合每玩家1張)、非戰鬥術(當回合用過不可再用)
- [ ] 2.8 實作戰鬥開始確認(バトル・イン):確認/讓過強制攻擊/插入行動使確認失效
- [ ] 2.9 實作戰鬥五步驟:攻擊宣告(付費、宣告時定目標與擲硬幣)、防禦宣告(可不防)、戰鬥中效果輪流、魔力勝負(不防=0、同值防勝、無效化=攻擊失敗)、解決
- [ ] 2.10 實作傷害解決:魔本傷害翻頁、魔物負傷/二度受傷棄掉(夥伴連動)、庇護(pending choice)、多項傷害受方定序、反擊(カウンター)
- [ ] 2.11 實作結束階段:效果與待命解決(回合玩家定序)、魔物消失處理(ADV)、強制翻頁+2MP、回合轉移
- [ ] 2.12 實作勝利條件與 ADV 規則:魔本耗盡/魔物全滅判定、最後一頁術費用 0
- [ ] 2.13 引擎規則測試:上述各項的 pytest 覆蓋(含 seed 重現測試),整局冒煙測試(腳本化指令序列打完一局)
