# Spec Delta

## ADDED Requirements

### Requirement: 開始階段的翻頁提醒
開始階段輪到自己(回合玩家)、可以翻頁時,行動欄停在目前頁的「不翻頁」按鈕 SHALL 附註「按魔書的 › 往後翻閱,選擇翻幾張(最多 N 張)」(N 為能翻的最多張數);自己魔書的「›」翻閱按鈕 SHALL 發光提示,直到翻閱到最多能翻的對頁。不能翻頁(已翻開最後一對頁)時 MUST NOT 顯示附註與發光。其他階段與對手的魔書 MUST NOT 發光。動畫減少的設定下以靜態的醒目樣式呈現。四種語言都有對應文字。

#### Scenario: 開始階段的提醒
- **WHEN** 開始階段輪到自己,魔書停在目前頁,最多可翻 3 張
- **THEN** 「不翻頁」按鈕下行顯示「按魔書的 › 往後翻閱,選擇翻幾張(最多 3 張)」,魔書的「›」發光

#### Scenario: 翻閱到上限
- **WHEN** 玩家按「›」翻閱到第 3 個對頁(翻 3 張)
- **THEN** 「›」不再發光,行動欄為「翻 3 張」

#### Scenario: 不能翻頁
- **WHEN** 開始階段,自己的魔書已翻開最後一對頁
- **THEN** 「不翻頁」沒有附註,「›」不發光

#### Scenario: 戰鬥階段
- **WHEN** 進入戰鬥階段
- **THEN** 魔書的「›」不發光
